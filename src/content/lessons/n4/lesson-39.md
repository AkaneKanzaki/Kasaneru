## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa memakai 〜ところだ untuk momen yang presisi — tepat sedang, baru akan, baru selesai — dan 〜たばかり untuk "baru saja" yang fokus pada "waktunya belum lama".

## Penjelasan

〜ところだ = "tepat…" — menangkap MOMEN yang presisi. Ada tiga bentuk, dan bentuk kata kerjanya menentukan artinya:

- V-te + いるところだ = tepat SEDANG: たべているところです (tepat sedang makan)
- V-kamus + ところだ = baru AKAN: でかけるところです (baru akan pergi)
- V-ta + ところだ = baru SELESAI: かえってきたところです (baru saja sampai)

〜たばかり = "baru saja…" — fokusnya BUKAN momen, melainkan "waktunya BELUM LAMA" (mungkin sepuluh menit lalu, bukan detik ini).

Bedakan nuansa waktunya lewat minimal pair:

- かえってきたところです = momen kepulangannya (pintu baru saja ditutup!).
- かえってきたばかりです = waktunya belum lama (mungkin sudah sempat ganti baju).

Bonus N4: V-kamus + ところでした = "hampir…". のりおくれるところでした berarti hampir ketinggalan (tapi tidak jadi).

Dua belas kanji pelajaran ini: 誌 (ざっし = majalah), 典 (じてん = kamus), 試 (ためす = mencoba), 章 (しょう = bab), 節 (せつ = bagian), 吹 (ふく = bertiup), 酔 (よう = mabuk), 数 (かぞえる = menghitung), 世 (よ = dunia), 接 (せっする = berhubungan), 折 (おる = melipat), 設 (もうける = memasang).

## Contoh kalimat

1. いま ごはんを たべているところです。(Saya tepat sedang makan.)
2. これから でかけるところです。(Saya baru akan pergi.)
3. たったいま かえってきたところです。(Saya baru saja pulang.)
4. さっき ごはんを たべたばかりです。(Saya baru makan — belum lama.)
5. あぶなく でんしゃに のりおくれるところでした。(Saya hampir ketinggalan kereta.)
6. さくらの はなが さいたばかりです。(Bunga sakura baru saja mekar.)
7. いま ふろに はいっているところです。あとで でんわします。(Saya tepat sedang berendam. Nanti saya telepon.)
8. この ほんは かったばかりです。まだ よんでいません。(Buku ini baru saya beli. Belum saya baca.)

## Latihan

1. Ubah: たべている + ところだ → ______
2. Ubah (baru akan pergi): でかける → ______
3. Ubah (baru selesai pulang): かえってくる → ______
4. Pilih: さっき たべた（ところです / ばかりです）。
5. Terjemahkan ke bahasa Jepang: "Saya hampir jatuh." (jatuh = ころぶ) → ______
6. Buat minimal pair: tulis かえってきたところです lawan かえってきたばかりです beserta penjelasan bedanya.
7. Pilih (tepat sedang mandi): いま シャワーを（あびているところです / あびたばかりです）。
8. Betulkan: たべているばかりです → ______

8. たべたばかりです

## Tips / pola penting

- 〜ところだ = presisi MOMEN; 〜たばかり = presisi JARAK WAKTU ("belum lama").
- 〜ばかり menempel pada bentuk-TA: たべたばかり ✓, たべているばかり ✗.
- 〜ところでした = "hampir…" — pola favorit soal JLPT, jangan sampai terlewat.
- Hati-hati pasangan pengecoh: でかけるところです (baru akan berangkat) lawan でかけたところです (baru selesai berangkat — sudah pergi!).

## Ringkasan

- V-te + いるところ: tepat sedang. V-kamus + ところ: baru akan. V-ta + ところ: baru selesai.
- V-ta + ばかり: baru saja, dengan fokus "waktunya belum lama".
- V-kamus + ところでした: "hampir…".
- Kanji: 誌(ざっし) 典(じてん) 試(ためす) 章(しょう) 節(せつ) 吹(ふく) 酔(よう) 数(かぞえる) 世(よ) 接(せっする) 折(おる) 設(もうける).

## Tugas & catatan SRS

Tugas: catat lima momen harimu — satu "tepat sedang" (〜ているところ), satu "baru akan" (〜ところ), satu "baru selesai" (〜たところ), satu "belum lama" (〜たばかり), dan satu "hampir" (〜ところでした). Masukkan ke deck SRS: 〜ているところだ, 〜ところだ, 〜たところだ, 〜たばかり, 〜ところでした.
