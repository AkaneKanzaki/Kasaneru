## Lesson goals

After this lesson, you'll be able to use V-ます + やすい ("easy to…") and + にくい ("hard to…"), briefly tell them apart from 〜づらい, and not be fooled by やすい which also means "cheap".

## Explanation

V-ます (drop ます) + やすい = "easy to…". V-ます (drop ます) + にくい = "hard to…".

- かく → かきやすい (easy to write with)
- おぼえる → おぼえにくい (hard to memorize)

Briefly distinguish from 〜づらい: づらい is used when something is hard because of a HEAVY, temporary CONDITION, while にくい is for difficulty from an INHERENT trait.

- じが ちいさくて よみづらい (hard to read because the letters are small — a condition)
- かんじが おぼえにくい (kanji are just hard to memorize — a trait)

NOTE: やすい also means "cheap"! Context decides.

- この ペンは かきやすいです。(easy to write with)
- この ペンは やすいです。(cheap)

The kanji spellings differ, but in kana-only tests rely on context: when it attaches to V-ます, it means "easy".

This lesson's twelve kanji: 起 (おきる = to wake up), 台 (だいどころ = kitchen), 掃・除 (そうじ = cleaning), 鏡 (かがみ = mirror), 順 (じゅん = order), 初 (はじめて = for the first time), 所 (ところ = place), 署 (しょ = office), 助 (たすける = to help), 昭 (しょう = bright), 消 (けす = to extinguish).

## Example sentences

1. この ペンは かきやすいです。(This pen is easy to write with.)
2. この ほうちょうは きれにくいです。(This kitchen knife is hard to cut with.)
3. だいどころが せまいので、りょうりしにくいです。(The kitchen is narrow, so it's hard to cook.)
4. この かがみは おおきくて みやすいです。(This mirror is big and easy to see in.)
5. にほんごの かんじは おぼえにくいです。(Japanese kanji are hard to memorize.)
6. あさは おきにくいです。めざましを みっつ かけます。(Mornings are hard to wake up in. I set three alarms.)
7. この アプリは つかいにくいです。もっと べんりなのが ほしいです。(This app is hard to use. I want a more convenient one.)
8. この みせの りょうりは やすくて おいしいです。(This shop's food is cheap and delicious.)

## Tips / key patterns

- 〜づらい for TEMPORARY or conditional difficulty; 〜にくい for difficulty INHERENT to the thing itself.
- やすい is double: "easy" always attaches to V-ます, while "cheap" stands alone as an adjective.
- Negative form: 〜にくいです → 〜にくくないです.
- This pattern is very productive — almost any verb can take 〜やすい/〜にくい, so it often appears in tests.

## Summary

- V-ます + やすい = "easy to…"; V-ます + にくい = "hard to…".
- 〜づらい (briefly): hard because of conditions, not inherent traits.
- Double やすい: "easy" (V-ます + やすい) versus "cheap" (adjective).
- Kanji: 起(おきる) 台(だいどころ) 掃・除(そうじ) 鏡(かがみ) 順(じゅん) 初(はじめて) 所(ところ) 署(しょ) 助(たすける) 昭(しょう) 消(けす).
