## Lesson goals

After this lesson, you'll be able to use 〜ばかり for excessive "only" ("nothing but"), 〜うちに for "while still…" before things change, and tell them apart from だけ (neutral) and 間に ("during").

## Explanation

〜ばかり = excessive "only" ("nothing but"): V-te + ばかり, or noun + ばかり.

- たべてばかりいる (eating all the time), ゲームばかりしている (playing games nonstop)

〜うちに = "while still…"/"before…" — an opportunity BEFORE things change.

- わかいうちに (while still young), わすれないうちに (before forgetting)

Briefly distinguish from two similar patterns:

- 〜ばかり versus 〜だけ: だけ is neutral ("only"), ばかり is excessive ("nothing but"). ビールだけのむ (only drinking beer — neutral) versus ビールばかりのむ (drinking nothing but beer — excessive).
- 〜うちに versus 〜間に: 間に = "during" (a span of action), うちに = "before it changes" (an opportunity).

This lesson's fifteen kanji: 航 (こうくう = aviation), 船 (ふね = ship), 陸 (りく = land), 割 (わる = to split), 倍 (ばい = times), 戦 (たたかう = to fight), 善 (よい = good), 祖 (そふ = grandfather), 素 (す = plain), 倉 (そうこ = warehouse), 捜 (さがす = to search for), 展 (てんじ = exhibition), 訳 (わけ = reason), 億 (おく = one hundred million), 間 (あいだ = between).

## Example sentences

1. Budiは ゲームばかりしています。(Budi does nothing but play games.)
2. かれは ビールばかり のんでいます。(He drinks nothing but beer.)
3. わかいうちに いろいろな くにへ いきたいです。(While I'm still young, I want to go to various countries.)
4. あかるいうちに かえりましょう。(Let's go home while it's still light.)
5. でんしゃに のっている間に ほんを よみました。(While riding the train, I read a book.)
6. わすれないうちに メモしましょう。(While you still remember, let's take notes.)
7. あついうちに たべましょう。(Let's eat while it's still hot.)
8. ふねから りくが みえるうちに しゃしんを とりましょう。(While land is still visible from the ship, let's take photos.)

## Practice

1. Change: たべる → ______ばかりいる。
2. Choose the excessive one: ビールを（だけ / ばかり）のむ。
3. Choose: わすれない（うちに / 間に）メモする。
4. Choose: のっている（うちに / 間に）ほんを よむ。
5. Translate into Japanese: "While you're still young, study a lot." → ______
6. Make a minimal pair: write ビールだけのむ versus ビールばかりのむ with an explanation of the tone difference.
7. Change: あそぶ → ______ばかりしている。
8. Fix: わかいあいだに りょこうしましょう → for the meaning "while still young".

### Answer key

1. たべて
2. ばかり
3. うちに
4. 間に
5. わかいうちに たくさん べんきょうしましょう。
6. (example) ビールだけのみます = only drinking beer (neutral). / ビールばかりのみます = drinking nothing but beer (excessive).
7. あそんで
8. わかいうちに りょこうしましょう。

## Tips / key patterns

- 〜ばかり attaches to the TE-form: たべてばかり ✓, たべるばかり ✗.
- 〜うちに is always about "before it changes" — look for state/negative words before it (わすれない, あかるい, わかい).
- だけ is neutral, ばかり is excessive — JLPT questions love asking about this nuance difference.
- The 〜ないうちに ("before…") pattern appears very often in tests — memorize it as one package.

## Summary

- V-te + ばかり: excessive "only" ("nothing but", "nonstop").
- 〜うちに: "while still…" or "before…" (an opportunity before things change).
- だけ (neutral) versus ばかり (excessive); 間に (during) versus うちに (before it changes).
- Kanji: 航(こうくう) 船(ふね) 陸(りく) 割(わる) 倍(ばい) 戦(たたかう) 善(よい) 祖(そふ) 素(す) 倉(そうこ) 捜(さがす) 展(てんじ) 訳(わけ) 億(おく) 間(あいだ).
