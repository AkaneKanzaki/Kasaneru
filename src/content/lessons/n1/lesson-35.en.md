## Lesson goals

After this lesson, you can write a である体 essay with at least five well-chosen yojijukugo — supporting the argument, not decoration.

## Explanation

A good N1 essay uses yojijukugo as a *meaning shortcut*: one idiom replaces a paragraph of explanation. The rule: one yojijukugo per idea, and it must strengthen the 主張, not decorate.

**The M7 essay pattern.** 序論: raise the issue with 一期一会. 本論: develop with 温故知新, 対比 with 十人十色, solve with 臨機応変. 結論: close with 大器晩成. Five idioms, five functions — this is 起承転結 brought to life.

**Model essay.** 〔文語・である体〕 地方の 過疎化は 一期一会の 出会いを 奪いつつある。温故知新の 視点から見れば、稚内や 釧路の 港町は かつて 北の 玄関として 栄えた。十人十色の 暮らしを 守るには、臨機応変の 支援が 要る。函館の 朝市が 教えるのは、大器晩成の まちづくりである。

Each yojijukugo carries one function: the problem, the perspective, diversity, the solution, hope.

This lesson's kanji: 苫 (とま), 釧 (くしろ, e.g. 釧路), 稚 (ち, e.g. 稚内), 内 (ない, e.g. 稚内), 函 (かん, e.g. 函館), 館 (かん, e.g. 函館), 宮 (きゅう, e.g. 宮城), 城 (じょう, e.g. 宮城), 葉 (よう), 奈 (な, e.g. 奈良), 潟 (かた, e.g. 新潟), 富 (ふ, e.g. 富山), 長 (ちょう, e.g. 長野), 静 (せい, e.g. 静岡), 岡 (こう, e.g. 静岡), 知 (ち), 京 (きょう, e.g. 京都), 阪 (はん, e.g. 大阪), 兵 (へい, e.g. 兵庫), 良 (りょう).

## Example sentences

1. 〔文語〕 序論では 一期一会の 問題意識を 提示し、読み手を 引き込む。(In the introduction, present a once-in-a-lifetime problem to draw the reader in.)
2. 〔文語〕 本論の 対比には 十人十色の 視点が 有効である。(For contrast in the main body, a perspective of diversity is effective.)
3. 〔ビジネス〕 企画書の 結論に 大器晩成の 展望を 添えると 説得力が 増す。(Adding a late-blooming outlook to a proposal's conclusion increases its persuasiveness.)
4. 〔文語〕 論拠の 引用には 温故知新の 姿勢が 求められる。(Citing evidence calls for an attitude of learning from the past.)
5. 〔日常〕 エッセイに 四字熟語を 詰め込みすぎると、逆に 読みにくく なるよ。(An essay crammed with too many idioms is actually harder to read.)
6. 〔文語〕 臨機応変の 対応こそ、五里霧中を 打ち破る 鍵である。(A flexible response is precisely the key to breaking through confusion.)
7. 〔報道〕 長野の りんご 農家は、以心伝心の 連携で 品牌を 守ってきた。(Nagano apple farmers have protected their brand through wordless teamwork.)
8. 〔文語〕 結論は 主張の 再確認であり、新しい 四字熟語を 出す 場では ない。(The conclusion restates the claim; it is not the place to introduce new idioms.)

## Exercises

1. The yojijukugo fitting a 序論 that raises a precious problem: ______.
2. The yojijukugo fitting an essay ending with long-term hope: ______.
3. Choose the correct one: 結論 is (restating the 主張 / the place for new idioms).
4. Choose the correct one: the 本論 uses 十人十色 for (comparing perspectives / citing data).
5. Write a 3-sentence mini-essay (序論–本論–結論) about your city, using at least 2 yojijukugo: ______
6. The common mistake: (one idiom per function / cramming in as many idioms as possible).

### Answer key

1. 一期一会
2. 大器晩成
3. restating the claim
4. comparing perspectives
5. (example) 序論: 私の 町との 出会いは 一期一会であった。本論: 十人十色の 文化が 交わる 港町である。結論: 大器晩成の 発展を 信じたい。
6. cramming in as many idioms as possible

## Tips / key patterns

- One yojijukugo = one rhetorical function; if it can be deleted without damaging the argument, cut it.
- At most 5–6 idioms per 800字 essay; more than that smells of showing off memorization.

## Summary

- M7 pattern: 序論 (一期一会) → 本論 (温故知新, 十人十色, 臨機応変) → 結論 (大器晩成).
- One yojijukugo = one rhetorical function; 5–6 idioms per 800字 essay is enough.
- である体 register.
- Kanji: 釧路, 稚内, 函館, 宮城, 奈良, 新潟, 富山, 長野, 静岡, 京都, 大阪, 兵庫.
