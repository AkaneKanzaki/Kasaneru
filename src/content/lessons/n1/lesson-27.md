## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa memakai dua pola N1 〜も顧みず dan 〜をものともせず ("tanpa memedulikan / tanpa menganggap sebagai halangan") untuk menggambarkan tekad yang mengabaikan rintangan. Keduanya sering muncul di esai, biografi, dan berita tentang orang-orang yang menerobos kesulitan.

## Penjelasan

**1. 〜も顧みず (pola 1).** Rumus: kata benda + も顧みず. Arti: "tanpa memedulikan …" / "tanpa menoleh pada …". Kata kerja 顧みる (かえりみる) berarti "menoleh ke belakang / memedulikan", sehingga bentuk ず-nya berarti mengabaikan sama sekali.

- 危険も顧みず火の中に飛び込んだ。(Menerjang ke dalam api tanpa memedulikan bahaya.)
- 命も顧みず戦った。(Bertempur tanpa memedulikan nyawa.)

Ungkapan baku: 危険も顧みず, 命も顧みず, 危険を顧みず (dengan を juga ada, tetapi も lebih lazim di pola N1 ini).

**2. 〜をものともせず (pola 2).** Rumus: kata benda + をものともせず. Arti: "tanpa menganggap … sebagai halangan". Kata もの di sini selalu ditulis dengan kana.

- けがをものともせず出場した。(Tampil bertanding tanpa menganggap cederanya sebagai halangan.)
- 困難をものともせず研究を続けた。(Melanjutkan penelitian tanpa menganggap kesulitan sebagai rintangan.)

Bedakan nuansanya: 〜も顧みず = "mengabaikan, tidak menoleh" (fokus pada sikap tidak peduli); 〜をものともせず = "tidak gentar, tidak menganggap sebagai masalah" (fokus pada keteguhan menghadapi rintangan). Dalam banyak konteks keduanya bisa bertukar, tetapi kolokasi bakunya berbeda: 命・危険 → も顧みず; 困難・逆境・けが → をものともせず.

Dua puluh kanji pelajaran ini: 啜（てつ）・戾（れい）・鷙（し）・斜（しゃ）・傾（けい）・欹（き）・曄（よう）・燿（よう）・焜（こん）・煌（こう）・哄（こう）・馨（けい）・馥（ふく）・郁（いく）・甘（かん）・酸（さん）・鹹（かん）・嫩（どん）・装（そう）・髷（まげ）.

## Contoh kalimat

1. 〔報道〕 消防士は危険も顧みず火の中に飛び込んだ。(Petugas pemadam kebakaran menerjang ke dalam api tanpa memedulikan bahaya.)
2. 〔文語〕 彼は世論の反対も顧みず改革を断行した。(Ia melaksanakan reformasi tanpa memedulikan penentangan opini publik.)
3. 〔報道〕 選手はけがをものともせず試合に出場した。(Atlet itu tampil bertanding tanpa menganggap cederanya sebagai halangan.)
4. 〔文語〕 彼女は困難をものともせず研究を続けた。(Ia melanjutkan penelitian tanpa menganggap kesulitan sebagai rintangan.)
5. 〔文学〕 兵士は命も顧みず仲間を守った。(Prajurit itu melindungi rekannya tanpa memedulikan nyawanya sendiri.)
6. 〔日常〕 彼は周りの反対をものともせず留学を決めた。(Ia memutuskan berangkat留学 tanpa menganggap penentangan sekitarnya sebagai halangan.)
7. 〔文語〕 彼女は名誉も地位も顧みず真実を語った。(Ia menyampaikan kebenaran tanpa memedulikan nama baik maupun kedudukannya.)

## Latihan

1. Pilih yang tepat: 彼は命___戦った。(も顧みず / をものともせず)
2. Isi dengan pola yang tepat: 彼女は逆境___研究を続けた。
3. Terjemahkan ke bahasa Jepang: "Ia maju tanpa memedulikan kecaman." → ______
4. 顧みる dibaca: (かえりみる / かえりみず).
5. 〜をものともせず berarti: (menganggap sebagai halangan besar / tidak menganggap sebagai halangan).
6. Susun menjadi kalimat yang benar: 彼は / 危険 / も顧みず / 助けに / 向かった → ______

## Tips / pola penting

- Hafalkan kolokasinya: 命・危険 → も顧みず; 困難・逆境 → をものともせず. Soal sering menguji kolokasi baku ini.
- もの pada 〜をものともせず selalu kana — kalau ditulis dengan kanji 物, itu salah.
- Bentuk ず adalah bentuk sastra dari ない; jangan tertukar dengan 〜も顧みない yang bernada percakapan biasa.

## Ringkasan

- 〜も顧みず (kata benda + も): "tanpa memedulikan …" — sikap mengabaikan; kolokasi: 命も顧みず, 危険も顧みず.
- 〜をものともせず (kata benda + を): "tanpa menganggap … sebagai halangan" — keteguhan menghadapi rintangan; もの selalu kana.
- Nuansa: 顧みず = tidak menoleh/tidak peduli; ものともせず = tidak gentar.
- Kanji: 啜戾鷙斜傾欹曄燿焜煌哄馨馥郁甘酸鹹嫩装髷.
