## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa menyebutkan alasan melakukan sesuatu dan memberi pendapat sederhana tentang makanan, barang, atau kegiatan dalam bahasa Jepang.

## Kosakata baru

| Jepang | Cara baca | Arti |
|---|---|---|
| 味 | あじ | rasa |
| 好き | すき | suka |
| おいしい | おいしい | enak |
| まずい | まずい | tidak enak |
| 辛い | からい | pedas |
| 甘い | あまい | manis |
| 便利 | べんり | praktis, nyaman |
| 不便 | ふべん | tidak praktis |

| 危険 | きけん | berbahaya |
| 静か | しずか | tenang |
| 賑やか | にぎやか | ramai |
| 高い | たかい | mahal, tinggi |
| 安い | やすい | murah |

## Penjelasan

Partikel から dipakai untuk menyatakan **alasan**: "karena …". Polanya: **kalimat (bentuk biasa) + から**.

- 暑いから、エアコンをつけます。= Karena panas, saya menyalakan AC.
- 安いから、買います。= Karena murah, saya membeli.

Semua jenis predikat bisa dipakai sebelum から: kata kerja bentuk biasa (行くから), kata sifat-i bentuk biasa (おいしいから), kata sifat-na bentuk biasa + だ (静かだから), kata benda + だ (学生だから). Kalimat dengan から biasanya menjawab pertanyaan どうして/なぜ (kenapa). Catatan: jangan campur から (alasan) dengan から/まで (dari/sampai waktu) — konteksnya berbeda.

## Contoh kalimat

1. どうしてインドネシア語を勉強していますか。
   - Kenapa kamu belajar bahasa Indonesia?
2. インドネシアで働きたいからです。
   - Karena saya ingin bekerja di Indonesia.
3. このワルンは安くておいしいから、よく来ます。
   - Karena warung ini murah dan enak, saya sering datang.
4. 辛いから、あまり食べられません。
   - Karena pedas, saya tidak bisa makan banyak.
5. 明日は休みだから、うちでゆっくりします。
   - Karena besok libur, saya santai di rumah.
6. この道は危ないから、気をつけてください。
   - Karena jalan ini berbahaya, hati-hatilah.
7. ジャカルタはにぎやかだから、好きです。
   - Karena Jakarta ramai, saya suka.

## Latihan

1. Pilihan ganda: "Karena murah, saya membeli" adalah …
   - a. 安いから、買います b. 安くてから、買います c. 安いのでから、買います
2. Isian: 頭が痛い（いたい）＿＿＿、薬を飲みます。
3. Isian: どうして来なかったのですか。→ 電車が遅れた＿＿＿です。
4. Susun kalimat: からです / 寒い / 早く帰りたい → …?
5. Terjemahkan ke Jepang: "Karena lapar, saya makan nasi goreng."
6. Terjemahkan ke Indonesia: 忙しいから、パーティーに行けません。
7. Pilihan ganda: Bentuk benar untuk kata sifat-na sebelum から: …
   - a. 静かから b. 静かだから c. 静かなから

### Kunci jawaban

1. a — 安いから、買います
2. から (bentuk biasa: 痛いから)
3. から
4. 寒いから、早く帰りたいです。
5. おなかがすいたから、ナシゴレンを食べます。
6. Karena sibuk, saya tidak bisa pergi ke pesta.
7. b — 静かだから

## Tips / pola penting

- Sebelum から selalu bentuk **biasa** (plain form), bukan bentuk sopan ます/です.
- Kata sifat-na dan kata benda butuh だ: 有名だから, 雨だから.
- から bisa di akhir kalimat jawaban: なぜですか。→ 安いからです。
- Perbedaan nuansa: ～から terdengar lebih langsung, ～ので lebih lembut (ので dipelajari di level berikutnya; untuk N5, から sudah cukup).

## Ringkasan

- ～から = karena (menyatakan alasan).
- Pola: kalimat bentuk biasa + から.
- Menjawab どうして/なぜ.
- Kata sifat-na/kata benda: tambah だ (静かだから).
- Kanji hari ini: 味 (rasa), 好 (suka; 好き).

## Tugas & catatan SRS

- Tulis 5 alasan dalam bahasa Jepang: 2 tentang makanan favoritmu, 3 tentang kegiatanmu hari ini.
- Masukkan ke deck SRS: 味, 辛い, 甘い, 便利, 安全, 賑やか, ～から.
