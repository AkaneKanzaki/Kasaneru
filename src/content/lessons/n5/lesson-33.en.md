## Lesson goals

After this lesson, you can express the desire to have something and state likes or dislikes about food, things, and activities in Japanese.

## Explanation

Two patterns for "want" and "like" toward **things** (not actions):

**1. ～がほしいです** = "want (to have) …"
- 新しいかばんがほしいです。= I want a new bag.
- It behaves like an i-adjective: ほしくないです (don't want), ほしかったです (wanted … before).

**2. ～が好きです / ～が嫌いです** = "like / dislike …"
- 寿司が好きです。= I like sushi.
- 納豆が嫌いです。= I dislike natto.

Key difference: ～たい is for the desire to **do an action** (たべたい = want to eat), while ～がほしい is for the desire to **have a thing** (ケーキがほしい = want a cake). Both are only for yourself; for third persons use ～たがっている/ほしがっている (N4).

## Example sentences

1. 誕生日に新しい自転車がほしいです。
   - I want a new bicycle for my birthday.
2. 暑いから、冷たいジュースがほしいです。
   - Because it's hot, I want cold juice.
3. ブディさんは辛い食べ物が大好きです。
   - Budi loves spicy food.
4. 私はパクチーが嫌いです。
   - I don't like coriander leaves.
5. 母は果物が好きですが、父はあまり好きじゃありません。
   - Mom likes fruit, but Dad doesn't like it much.
6. 子供のとき、おもちゃがほしかったです。
   - When I was a child, I wanted toys.
7. シンタさんは勉強が好きだから、成績がいいです。
   - Because Sinta likes studying, her grades are good.

## Practice

1. Multiple choice: "I want a new camera" is …
   - a. 新しいカメラをほしいです b. 新しいカメラがほしいです c. 新しいカメラがほしいます
2. Fill in: 私は泳ぐ（およぐ）＿＿＿好きです。
3. Fill in: 弟は野菜が＿＿＿です。(dislike)
4. Arrange into a sentence: です / がほしい / 時間 / もっと → …?
5. Translate into Japanese: "I don't want anything as a gift."
6. Translate into English: 昔は肉が嫌いでしたが、今は好きです。
7. Multiple choice: The correct pair: …
   - a. 映画を見たいです = want to watch a movie b. 映画がほしいです = want to watch a movie c. 映画をほしいです = want to own a movie

### Answer key

1. b — 新しいカメラがほしいです
2. の (verb + のが好き)
3. 嫌い
4. もっと時間がほしいです。
5. プレゼントは何もほしくありません。/ プレゼントはいりません。
6. I used to dislike meat, but now I like it.
7. a — 見たい for the action of watching; ほしい for things

## Tips / important patterns

- Remember the pairings: たい ↔ actions, ほしい ↔ things. Mixing them up is a classic mistake.
- Verb + のが好きです for "like doing …": 泳ぐのが好きです.
- 好き/嫌い + な to describe a noun: 好きな食べ物 (favorite food).
- ほしい is very direct; when asking someone else, it's more polite: ～をいただけますか (N4) or ～がほしいんですが….

## Summary

- ～がほしいです = want to have … (a thing).
- ～が好きです / ～が嫌いです = like / dislike ….
- ～たい for actions, ほしい for things.
- All behave like i-adjectives.
- Today's kanji: 勉, 強 (study; 勉強).
