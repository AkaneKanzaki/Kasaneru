## Lesson goals

After this lesson, you can make polite requests with ～てください and give simple instructions. You can use this pattern in everyday conversation.

## Explanation

The polite request pattern:

- **V-て + ください**

Take the て form from the last lesson and attach ください.

- まって ください (please wait)
- よんで ください (please read)
- おしえて ください (please tell me)

This pattern is used both ways: asking for help for yourself (たすけて ください = please help me) and giving instructions to others (しずかに して ください = please be quiet).

For a softer request, add すみません at the start: すみません、もういちど いって ください。(Excuse me, please say it once more.)

This lesson's three kanji: 手 (て = hand), 紙 (かみ = paper), 書 (かく = write).

## Example sentences

1. ゆっくり はなして ください。(Please speak slowly.)
2. この ぶんを よんで ください。(Please read this sentence.)
3. もういちど いって ください。(Please say it once more.)
4. ドアを しめて ください。(Please close the door.)
5. しずかに して ください。(Please be quiet.)
6. たすけて ください！(Please help me!)
7. この しゃしんを みて ください。(Please look at this photo.)
8. あした れんらくして ください。(Please contact me tomorrow.)

## Tips / important patterns

- Common mistake: using the ます form + ください (よみますください — wrong). Always て form + ください.
- ～てください is polite for most situations, but can feel too direct toward a superior. For the N5 exam, this pattern is enough.
- Don't confuse it with ～ないでください (please don't …), which you'll learn later — don't mix them up.
- In the JLPT, the ～てください pattern appears very often in conversation and instruction questions.

## Summary

- Pattern: V-て + ください = polite request.
- Used both to ask for help and to give instructions.
- Add すみません at the start to make it softer.
- Kanji: 手 (て), 紙 (かみ), 書 (かく).
