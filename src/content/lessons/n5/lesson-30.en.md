## Lesson goals

After this lesson, you can complain about something excessive ("too …") and ask about or explain how to do something in Japanese.

## Explanation

This lesson has two short patterns, each simple on its own.

**1. ～すぎます** = "too …" (excessive, with a complaining tone)
- Verb ます-stem (ます-form without ます) + すぎます: 食べすぎます = eat too much.
- I-adjective (without い) + すぎます: 高すぎます = too expensive.
- Na-adjective (without な) + すぎます: 静かすぎます = too quiet.

**2. ～方** = "how to …" (read かた)
- Verb ます-stem (ます-form without ます) + 方: 使い方 = how to use, 読み方 = how to read.
- Sentence pattern: ～方がわかりません (don't know how), ～方を教えてください (please teach me how).

Both attach to the **ます-stem** (ます-form without ます), so memorize each verb's ます-form first.

## Example sentences

1. 昨日はケーキを食べすぎました。
   - Yesterday I ate too much cake.
2. このバッグは高すぎます。
   - This bag is too expensive.
3. 昨日のテストは難しすぎました。
   - Yesterday's test was too difficult.
4. この漢字の読み方がわかりません。
   - I don't know how to read this kanji.
5. カメラの使い方を教えてください。
   - Please teach me how to use the camera.
6. ブディさんの話は早すぎて、よくわかりませんでした。
   - Budi speaks too fast, so I didn't really understand.
7. 新しいアパートは駅から遠すぎます。
   - The new apartment is too far from the station.

## Practice

1. Multiple choice: "Too hot (weather)" is …
   - a. 暑すぎます b. 暑いすぎます c. 暑さすぎます
2. Fill in: 飲み（飲む）＿＿＿＿ました。→ "drank too much"
3. Fill in: パソコンの （使う）＿＿＿＿を教えてください。
4. Arrange into a correct sentence: すぎます / 辛 / この料理は → …?
5. Translate into Japanese: "I don't know how to write a job application letter in Japanese."
6. Translate into Indonesian: 昨日の映画は長すぎました。
7. Multiple choice: The form that attaches to ～方 is …
   - a. dictionary form b. ます-stem (without ます) c. て-form

### Answer key

1. a — 暑すぎます (い is dropped)
2. 飲みすぎ (飲む → 飲み + すぎ)
3. 使い方 (使う → 使い + 方)
4. この料理は辛すぎます。
5. 日本語で履歴書の書き方がわかりません。
6. Yesterday's movie was too long.
7. b — ます-stem (without ます)

## Tips / important patterns

- I-adjectives: drop the い first (高い → 高すぎます). A common exception people get wrong: いい → よすぎます.
- ～すぎます has a negative/complaining tone. For a positive "very", use とても/すごく.
- ～方 is read かた, not ほう (方法, read ほうほう, is a separate noun).
- A combined pattern that often comes up: ～すぎて、… (too …, so …) as in example 6.

## Summary

- ～すぎます = too … (verb/adjective + すぎます).
- ～方 (かた) = how to … (ます-stem + 方).
- Both attach to the ます-stem or the adjective without い/な.
- Today's kanji: 遅 (slow), 近 (near), 遠 (far).
