## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa mengungkapkan keinginan memiliki sesuatu dan menyatakan suka atau tidak suka terhadap makanan, benda, dan kegiatan dalam bahasa Jepang.

## Penjelasan

Dua pola untuk "ingin" dan "suka" terhadap **benda** (bukan aksi):

**1. ～がほしいです** = "ingin (memiliki) …"
- 新しいかばんがほしいです。= Saya ingin tas baru.
- Berperilaku seperti kata sifat-i: ほしくないです (tidak ingin), ほしかったです (ingin … dulu).

**2. ～が好きです / ～が嫌いです** = "suka / tidak suka …"
- 寿司が好きです。= Saya suka sushi.
- 納豆が嫌いです。= Saya tidak suka natto.

Perbedaan kunci: ～たい untuk keinginan **melakukan aksi** (たべたい = ingin makan), ～がほしい untuk keinginan **memiliki benda** (ケーキがほしい = ingin kue). Keduanya hanya untuk diri sendiri; untuk orang ketiga pakai ～たがっている/ほしがっている (N4).

## Contoh kalimat

1. 誕生日に新しい自転車がほしいです。
   - Saya ingin sepeda baru untuk ulang tahun.
2. 暑いから、冷たいジュースがほしいです。
   - Karena panas, saya ingin jus dingin.
3. ブディさんは辛い食べ物が大好きです。
   - Budi sangat suka makanan pedas.
4. 私はパクチーが嫌いです。
   - Saya tidak suka daun ketumbar.
5. 母は果物が好きですが、父はあまり好きじゃありません。
   - Ibu suka buah, tetapi Ayah tidak begitu suka.
6. 子供のとき、おもちゃがほしかったです。
   - Waktu kecil, saya ingin mainan.
7. シンタさんは勉強が好きだから、成績がいいです。
   - Karena Sinta suka belajar, nilainya bagus.

## Latihan

1. Pilihan ganda: "Saya ingin kamera baru" adalah …
   - a. 新しいカメラをほしいです b. 新しいカメラがほしいです c. 新しいカメラがほしいます
2. Isian: 私は泳ぐ（およぐ）＿＿＿好きです。
3. Isian: 弟は野菜が＿＿＿です。(tidak suka)
4. Susun kalimat: です / がほしい / 時間 / もっと → …?
5. Terjemahkan ke Jepang: "Saya tidak ingin apa-apa untuk hadiah."
6. Terjemahkan ke Indonesia: 昔は肉が嫌いでしたが、今は好きです。
7. Pilihan ganda: Pasangan yang benar: …
   - a. 映画を見たいです = ingin menonton film b. 映画がほしいです = ingin menonton film c. 映画をほしいです = ingin memiliki film

### Kunci jawaban

1. b — 新しいカメラがほしいです
2. の (kata kerja + のが好き)
3. 嫌い
4. もっと時間がほしいです。
5. プレゼントは何もほしくありません。/ プレゼントはいりません。
6. Dulu saya tidak suka daging, tetapi sekarang suka.
7. a — 見たい untuk aksi menonton; ほしい untuk benda

## Tips / pola penting

- Ingat pasangannya: たい ↔ aksi, ほしい ↔ benda. Tertukar keduanya adalah kesalahan klasik.
- Kata kerja + のが好きです untuk "suka melakukan …": 泳ぐのが好きです.
- 好き/嫌い + な untuk menerangkan kata benda: 好きな食べ物 (makanan kesukaan).
- ほしい sangat langsung; saat meminta ke orang lain, lebih sopan: ～をいただけますか (N4) atau ～がほしいんですが….

## Ringkasan

- ～がほしいです = ingin memiliki … (benda).
- ～が好きです / ～が嫌いです = suka / tidak suka ….
- ～たい untuk aksi, ほしい untuk benda.
- Semuanya berperilaku seperti kata sifat-i.
- Kanji hari ini: 勉, 強 (belajar; 勉強).
