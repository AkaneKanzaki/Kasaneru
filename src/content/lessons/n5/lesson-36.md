## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa menyatakan kewajiban ("harus …") dan meniadakannya ("tidak harus … / tidak perlu …") dalam bahasa Jepang, misalnya untuk aturan perjalanan dan pekerjaan.

## Penjelasan

Dua pola berlawanan untuk kewajiban:

**1. ～なければならない** = "harus …" (wajib)
- Pembentukan: kata kerja bentuk-ない (tanpa ない) + ければ + ならない. Praktisnya: ganti ない → なければならない.
- いかない → いかなければならない = harus pergi
- たべない → たべなければならない = harus makan
- Khusus: する → しなければならない, くる → こなければならない.

**2. ～なくてもいいです** = "tidak harus … / tidak perlu …"
- Pembentukan: kata kerja bentuk-ない + くてもいいです.
- いかなくてもいいです = tidak harus pergi
- Bentuk santai: ～なくてもいい (tanpa です).

Jangan tertukar dengan ～てはいけません (tidak boleh) dari L25: なくてもいい = boleh tidak melakukan, sedangkan てはいけない = dilarang melakukan.

## Contoh kalimat

1. 明日までに書類を出さなければなりません。
   - Saya harus menyerahkan dokumen sampai besok.
2. 飛行機に乗る前にチケットを予約しなければなりません。
   - Sebelum naik pesawat, harus memesan tiket.
3. 会議には必ず出席しなければなりませんか。
   - Apakah harus hadir di rapat?
4. いいえ、出なくてもいいです。
   - Tidak, tidak harus hadir.
5. 旅行の前にパスポートを準備しなければなりません。
   - Sebelum bepergian, harus menyiapkan paspor.
6. 規則は守らなければなりません。
   - Peraturan harus dipatuhi.
7. 今日は別に急がなくてもいいです。
   - Hari ini tidak perlu terburu-buru.

## Latihan

1. Pilihan ganda: "Harus belajar" adalah …
   - a. 勉強しなければならない b. 勉強しなくてもいいです c. 勉強してはならない
2. Isian: 明日は早く （起きる）＿＿＿＿なりません。
3. Isian: 心配（しんぱい）し＿＿＿＿もいいですよ。
4. Susun kalimat: なりません / 飲まなければ / 薬を → …?
5. Terjemahkan ke Jepang: "Tidak harus datang besok."
6. Terjemahkan ke Indonesia: 飛行機が飛ぶ前に、安全の説明を聞かなければなりません。
7. Pilihan ganda: Lawan kata "harus …" adalah …
   - a. ～てはいけません b. ～なくてもいいです c. ～たいです

### Kunci jawaban

1. a — 勉強しなければならない (する → しなければならない)
2. 起きなければ (起きない → 起きなければ)
3. なくて (心配しない → 心配しなくてもいい)
4. 薬を飲まなければなりません。
5. 明日来なくてもいいです。
6. Sebelum pesawat terbang, harus mendengarkan penjelasan keselamatan.
7. b — ～なくてもいいです

## Tips / pola penting

- Bentuk pendek yang umum: ～なきゃ (いかなきゃ) — pahami saat mendengar, tetapi tulis bentuk penuh di ujian.
- ～なければならない terasa kuat/kaku; alternatif lebih lembut: ～ないといけない (N4).
- Perhatikan kontras JLPT: なければならない (harus) vs なくてもいい (tidak harus) vs てはいけない (dilarang).
- Kata kerja golongan III: する→しなければ、くる→こなければ — sering keluar di soal konjugasi.

## Ringkasan

- ～なければならない = harus … (ない → なければならない).
- ～なくてもいいです = tidak harus / tidak perlu ….
- Beda dengan ～てはいけません (dilarang).
- Kanji hari ini: 旅 (perjalanan; 旅行), 飛 (terbang; 飛行機).
