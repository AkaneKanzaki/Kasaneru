## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa membandingkan dua hal ("lebih … daripada …") dan menyatakan yang paling ("paling … di antara …") dalam bahasa Jepang.

## Kosakata baru

| Jepang | Cara baca | Arti |
|---|---|---|
| より | より | daripada |
| いちばん | いちばん | paling |
| 早い | はやい | cepat, awal |
| 寒い | さむい | dingin |
| 長い | ながい | panjang |
| 短い | みじかい | pendek |
| 広い | ひろい | luas |
| 狭い | せまい | sempit |
| 強い | つよい | kuat |
| 速い | はやい | cepat (kecepatan) |
| 遅い | おそい | lambat, terlambat |
| 有名 | ゆうめい | terkenal |
| ちょうど | ちょうど | tepat, pas |
| もっと | もっと | lebih (lagi) |

## Penjelasan

Ada dua pola perbandingan dasar di N5.

**1. A は B より ～です** = "A lebih … daripada B"
- バスは電車より安いです。= Bus lebih murah daripada kereta.

**2. ～の中で ～がいちばん ～です** = "Di antara …, … paling …"
- スポーツの中でサッカーがいちばん好きです。= Di antara olahraga, saya paling suka sepak bola.

Catatan penting: untuk membandingkan tiga hal atau lebih, pakai いちばん. Kata より juga bisa berarti "dari" untuk titik awal (東京より南 = di selatan Tokyo), tetapi di pelajaran ini fokus pada arti "daripada".

## Contoh kalimat

1. バイクは車より速いです。
   - Motor lebih cepat daripada mobil.
2. ジャカルタはスラバヤよりにぎやかです。
   - Jakarta lebih ramai daripada Surabaya.
3. 私の部屋は兄の部屋より広いです。
   - Kamar saya lebih luas daripada kamar kakak.
4. 季節の中で雨季がいちばん好きです。
   - Di antara musim, saya paling suka musim hujan.
5. クラスの中でブディさんがいちばん背が高いです。
   - Di antara (siswa) kelas, Budi paling tinggi.
6. この二つのカバンでは、赤いほうがいいです。
   - Di antara dua tas ini, yang merah lebih bagus.
7. 朝は夜より涼しいです。
   - Pagi hari lebih sejuk daripada malam hari.

## Latihan

1. Pilihan ganda: "Kucing lebih kecil daripada anjing" adalah …
   - a. 猫は犬より小さいです b. 犬は猫より小さいです c. 猫が犬より小さいです
2. Isian: 果物の中でマンゴーが＿＿＿＿好きです。
3. Isian: 飛行機は船＿＿＿＿早いです。
4. Susun kalimat: より / 日本語は / 難しいです / 英語 → …?
5. Terjemahkan ke Jepang: "Di antara minuman, saya paling suka es teh."
6. Terjemahkan ke Indonesia: 冬は夏より寒いです。
7. Pilihan ganda: Kalimat yang benar untuk 3 hal atau lebih: …
   - a. A は B よりいちばんです b. ～の中で～がいちばんです c. A より B がいちばんです

### Kunci jawaban

1. a — 猫は犬より小さいです
2. いちばん
3. より
4. 日本語は英語より難しいです。
5. 飲み物の中でアイスティーがいちばん好きです。
6. Musim dingin lebih dingin daripada musim panas.
7. b — ～の中で～がいちばんです

## Tips / pola penting

- Urutan jangan terbalik: A は B より (A yang dibandingkan dulu, lalu pembandingnya).
- の中で boleh dihilangkan bila konteksnya jelas: サッカーがいちばん好きです.
- Pola alternatif: A と B とでは、A のほうが～です (di antara A dan B, A lebih …) — sering muncul di listening.
- 早い punya dua arti: "awal" dan "cepat"; 速い khusus "cepat (kecepatan)".

## Ringkasan

- A は B より ～です = A lebih … daripada B.
- ～の中で ～がいちばん ～です = paling … di antara ….
- より = daripada; いちばん = paling.
- Kanji hari ini: 寒 (dingin; 寒い), 早 (awal/cepat; 早い).

## Tugas & catatan SRS

- Bandingkan 3 hal di sekitarmu: 2 kalimat より + 1 kalimat いちばん tentang kota, makanan, atau transportasi.
- Masukkan ke deck SRS: より, いちばん, 広い, 狭い, 長い, 短い, もっと.
