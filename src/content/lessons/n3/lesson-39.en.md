## Lesson goals

After this lesson, you can use three "as if" patterns: 〜んばかりに ("as if about to ..."), 〜とばかりに ("as if saying ..."), and 〜かのようだ ("as if ..."). You can also tell the three apart so you don't mix them up in N3 questions.

## Explanation

### 1. 〜んばかりに — as if about to ...

Pattern: どうしないけい (without ない) + んばかりに. Expresses something almost happening.

- なきんばかりによろこんだ (so happy as if about to cry).
- ふりんばかりのそら (a sky that looks about to rain).

### 2. 〜とばかりに — as if saying ...

Pattern: 「...」とばかりに. Expresses an attitude that seems to utter something.

- 「早くにげろ」とばかりに、猪がとっしんしてきた。(The wild boar charged as if saying "run away quickly".)

### 3. 〜かのようだ — as if ...

Pattern: ふつうけい + かのようだ. Expresses a comparison.

- 狐に会ったかのように、かれはおどろいてたちどまった。(He stopped in surprise as if he'd met a fox.)

Difference: んばかりに for things ALMOST happening; とばかりに for implied "words"; かのようだ for general comparisons.

The ten kanji in this lesson: 鴨 (かも = duck), 燕 (つばめ = swallow), 鷺 (さぎ = heron), 鶴 (つる = crane), 狐 (きつね = fox), 狸 (たぬき = tanuki), 猪 (いのしし = wild boar), 仲 (なか = relationship, as in なかま), 介 (かい = intermediary, as in ちゅうかい), 舶 (はく = ship, as in せんぱく).

## Example sentences

1. かれはなきんばかりによろこんだ。(He was so happy he looked about to cry.)
2. そらがおちてきんばかりにくらくなった。(The sky darkened as if about to fall down.)
3. くもが鶴のむれかのようにながれた。(Clouds drifted as if they were a flock of cranes.)
4. 狐に会ったかのように、かれはおどろいてたちどまった。(He stopped in surprise as if he'd met a fox.)
5. 「早くにげろ」とばかりに、猪がとっしんしてきた。(The wild boar charged as if saying "run away quickly".)
6. 燕が帰ってきたかのように、はるのけはいがした。(It felt like spring, as if the swallows had returned.)
7. かれはなにもしらんばかりにだまっていた。(He stayed silent as if he knew nothing.)
8. 船がしずまんばかりにかたむいた。(The ship tilted as if about to sink.)

## Tips / key patterns

- Common mistake: attaching んばかりに to the ます form (なきますばかりに). The correct form is the ない stem without ない.
- とばかりに always starts with a direct quote (...と). Without a quote, use かのようだ.
- かのようだ attaches to verbs, adjectives, and nouns.
- In N3 questions, distinguish "almost happening" (んばかりに) from "comparison" (かのようだ) by context.

## Summary

- 〜んばかりに = as if about to ... (almost happening).
- 〜とばかりに = as if saying ... (implied quote).
- 〜かのようだ = as if ... (comparison).
- Formation pattern: どうしないけい (without ない) + んばかりに.
- Kanji: 鴨 燕 鷺 鶴 狐 狸 猪 仲 介 舶 — birds, animals, and relations.
