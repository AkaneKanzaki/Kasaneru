## Lesson goals

After this lesson, you know how to use Study mode for your first full simulation: the time allocation for each N3 section, per-section strategy, how to use the explanations actively, and how to record error patterns. This lesson contains strategy — the questions come from the app's question bank.

## Explanation

**Study mode** = a full N3 simulation under study conditions: breaks between sections are allowed, you may view the explanation after answering, timer as a guide. Its purpose is to map your ability honestly — the data is used in L47 (the error clinic) and compared with the next two mocks.

**N3 timing (140 minutes):** もじ・ごい 30 minutes, ぶんぽう + どっかい 70 minutes, ちょうかい 40 minutes. In Study mode, split the middle block: 30 minutes grammar + 40 minutes reading. Record your actual time for each section.

**Estimated score target (practice benchmark):** total ≥95/180 with each section above the estimated ±19/60 threshold. Realistic target for the first mock: each section above the threshold with a safe margin. Remember: the app's score is an ESTIMATE, not the official JLPT score which uses statistical scaling.

**Using explanations actively:** read the かいせつ for wrong questions AND right-but-unsure questions. Each problem question → one log line: section | question type | cause | action. Example: どっかい | main idea | picking a detail as the answer | mark the first sentence of each paragraph.

## Example sentences

**もじ・ごい (30').** Start with what you've mastered most; max 60 seconds/question; stuck → mark and move on.

**ぶんぽう + どっかい (70').** Grammar (30'): read the sentence to the END before looking at the options. Reading (40'): apply L41–L42 (questions first, distinguish facts and opinions). Your concentration must span the full 70 minutes without breaking.

**ちょうかい (40').** The L43 protocol (read the questions first, note the 4Ks) + watch for the 4 L44 nuance distractors. Example of a fatal mistake: 50 minutes spent on grammar so reading is done in a panicked 20 minutes.

## Practice

1. What is the official time allocation for each N3 section? How is the middle block divided in Study mode?
2. What is the difference between Study mode and Real mode regarding breaks and explanations?
3. Besides wrong questions, what other questions must you read the explanation for? Why?
4. What is the estimated score target for the first mock, and what is the important note about the app's score?
5. Write the Study-mode one-line error log format plus one example.

### Answer key

1. もじ・ごい 30', ぶんぽう + どっかい 70', ちょうかい 40' (140' total). Middle block: 30' grammar + 40' reading.
2. Study mode allows breaks between sections and viewing explanations; Real mode allows neither.
3. Right-but-unsure questions — "right by guessing" can fail in the real exam.
4. Each section above the estimated threshold with a margin, total ≥95/180. The app's score = ESTIMATE, not the official JLPT score.
5. section | question type | cause | action. Example: ぶんぽう | 〜ばかりか | wrong meaning direction | write 3 sentences of your own using 〜ばかりか.

## Tips / key patterns

- A good Study mode produces an improvement list, not just a number.
- Don't repeat the same question set — memorized questions ruin the measurement. Use a different set for each mock.
- You may log the between-section breaks so the comparison with Real mode stays honest.

## Summary

- Study mode = a full simulation to map your ability; breaks and viewing explanations are allowed.
- N3 timing: もじ・ごい 30', ぶんぽう + どっかい 70' (30+40), ちょうかい 40'.
- Target: estimated total ≥95/180, each section above the estimated threshold with a margin.
- One log line per problem question — raw material for L47.
- Kanji checklist (strokes, read without hesitation): 極（せっきょくてき・せっきょくてき）・至（至る・いたる）・亘（亘る・わたる）。
