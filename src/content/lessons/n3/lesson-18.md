## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa memakai empat pola konsesi dan penyesalan: 〜とはいえ, 〜とはいうものの, 〜ものの, dan 〜ものを. Target utama: jangan tertukar antara ものの ("meskipun") dan ものを (penyesalan "padahal ...").

## Penjelasan

Empat pola — hafalkan tabel kontras ini:

| Pola | Arti | Nuansa |
| 〜とはいえ | meskipun ... | konsesi ringan: "katanya sih ..., tetapi" |
| 〜とはいうものの | meskipun dikatakan ... | lebih formal dari とはいえ |
| 〜ものの | meskipun ... (tetapi) | fakta A benar, namun ada kontras B |
| 〜ものを | padahal ... (sayang sekali) | PENYESALAN: andai saja ... |

**AWAS JEBAKAN:** ものの (meskipun) lawan ものを (penyesalan). Bedanya cuma satu kana (の lawan を), tetapi maknanya berlawanan arah — perangkap favorit JLPT.

Contoh: はるとはいえ; 安いとはいうものの; 安いものの; もっと 勉強しておけばよかったものを (penyesalan).

〜ものを selalu bernada keluhan, sering mengikuti bentuk 〜ばよかった.

Tujuh kanji pelajaran ini: 漆 (うるし = pernis), 藍 (あい = nila), 藤 (ふじ = wisteria), 桃 (もも = persik), 棟 (むね = bubungan atap), 軒 (のき = teritis), 塀 (へい = pagar tembok).

## Contoh kalimat

1. 4月とはいえ、朝晩は まだ 寒いです。(Meski sudah April, pagi dan malam masih dingin.)
2. 子どもとはいえ、約束は 約束です。(Meski anak-anak, janji tetap janji.)
3. 安いとはいうものの、ひんしつは わるくありません。(Meski dibilang murah, kualitasnya tidak buruk.)
4. この カメラは 安いものの、使いにくいです。(Kamera ini memang murah, tetapi sulit dipakai.)
5. もっと 早く じゅんびしておけばよかったものを。(Padahal andai saja saya bersiap lebih awal.)
6. 気をつけろと いったものを、かれは 聞きませんでした。(Padahal sudah saya bilang "hati-hati", dia tak mendengarkan.)
7. はるとはいえ、山の うえは まだ 雪が 残っています。(Meski sudah musim semi, salju di gunung masih tersisa.)
8. りゅうがくすると きめたものの、やはり ふあんでした。(Meski sudah memutuskan kuliah ke luar negeri, saya tetap cemas.)

## Latihan

1. はる______、まだ寒いです。(pakai とはいえ)
2. 安い______、使いにくいです。(pakai ものの)
3. もっと勉強しておけばよかった______。(penyesalan)
4. Yang tepat: かれはくるといった______、来なかった。(a. ものの / b. ものを)
5. Terjemahkan: "Meski anak-anak, dia sangat sopan." (sopan = れいぎただしい) → ______
6. 〜とはいうものの nadanya lebih ______ dari 〜とはいえ.
7. 高い + とはいえ → ______
8. Makna: ものの = ______; ものを = ______.

## Tips / pola penting

- Perangkap utama: ものの = konsesi, ものを = penyesalan. Satu kana mengubah seluruh makna.
- 〜ものを bernada keluhan; kalimatnya sering berakhir menggantung.
- 〜とはいえ dan 〜とはいうものの tidak bisa untuk penyesalan — itu wilayah 〜ものを.
- Keempat pola lebih formal dari けど; cocok untuk esai dan teks JLPT.

## Ringkasan

- 〜とはいえ = konsesi ringan: はるとはいえ, 子どもとはいえ.
- 〜とはいうものの = versi formal dari とはいえ.
- 〜ものの = "meskipun ..., tetapi ...": 安いものの.
- 〜ものを = penyesalan "padahal andai saja ...": 〜ばよかったものを.
- Jebakan utama: ものの (konsesi) lawan ものを (penyesalan).
- Kanji: 漆 (うるし), 藍 (あいいろ), 藤 (ふじ), 桃 (もも), 棟 (むね), 軒 (のきさき), 塀 (へい).

## Tugas & catatan SRS

Tugas: tulis 2 kalimat 〜とはいえ, 2 kalimat 〜ものの, dan 2 kalimat penyesalan 〜ものを. Masukkan ke deck SRS: はるとはいえ, 安いものの, 〜ばよかったものを, 漆, 藍, 藤, 桃, 棟, 軒先, 塀.
