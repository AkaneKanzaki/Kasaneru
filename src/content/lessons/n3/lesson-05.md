## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa membedakan 〜おかげで (berkat — selalu positif) dan 〜せいで (gara-gara — selalu negatif) lewat pasangan contoh yang kontras, serta memakai 〜うちに untuk menyatakan "selagi / mumpung" masih ada kesempatan.

## Penjelasan

**1. 〜おかげで (berkat — POSITIF).** Polanya: kata benda + の + おかげで, atau bentuk biasa lampau + おかげで. Hasilnya selalu hal yang baik.

- 先生の おかげで、試験に ごうかくできました。(Berkat guru, saya bisa lulus ujian.)
- 毎日 れんしゅうした おかげで、ほんばんは きんちょうしませんでした。(Berkat latihan setiap hari, saya tidak tegang saat tampil.)

**2. 〜せいで (gara-gara — NEGATIF).** Polanya sama: kata benda + の + せいで, atau bentuk biasa + せいで. Hasilnya selalu hal yang buruk.

- たいふうの せいで、飛行機が おくれました。(Gara-gara topan, pesawat terlambat.)
- れんしゅうしなかった せいで、ほんばんで しっぱいしました。(Gara-gara tidak latihan, saya gagal saat tampil.)

Bandingkan pasangan kontras ini — inilah inti pelajaran:

- れんしゅうした **おかげで**、せいこうした。(positif → おかげで)
- れんしゅうしなかった **せいで**、しっぱいした。(negatif → せいで)

Kesalahan klasik: memakai 〜おかげで untuk hal buruk. Itu salah total — untuk hal buruk wajib 〜せいで.

**3. 〜うちに (selagi / mumpung).** Polanya: bentuk biasa (bukan lampau) + うちに. Artinya "selagi keadaan masih begitu, lakukan sesuatu sebelum berubah". Kata benda memakai の (子どもの うちに).

- 明るい うちに 帰りましょう。(Pulanglah selagi masih terang.)
- わかい うちに、いろいろな くにへ 行きたいです。(Selagi muda, saya ingin pergi ke berbagai negara.)
- わすれない うちに、メモしておきます。(Selagi belum lupa, saya catat dulu.)

Tujuh kanji pelajaran ini: 閥 (ばつ = faksi, mis. 派閥), 拘 (こう = menahan), 逮 (たい = menangkap), 訴 (そ = menggugat, mis. そしょう), 却 (きゃく = menolak, mis. きゃっか), 審 (しん = memeriksa, mis. しんさ), 枠 (わく = batasan).

## Contoh kalimat

1. 先生の おかげで、試験に ごうかくできました。(Berkat guru, saya bisa lulus ujian.)
2. 友だちの おかげで、いい 仕事が 見つかりました。(Berkat teman, saya mendapatkan pekerjaan yang bagus.)
3. たいふうの せいで、飛行機が おくれました。(Gara-gara topan, pesawat terlambat.)
4. じゅうたいの せいで、かいぎに ちこくしました。(Gara-gara macet, saya terlambat rapat.)
5. れんしゅうした おかげで、ほんばんは きんちょうしませんでした。(Berkat latihan, saya tidak tegang saat tampil.)
6. れんしゅうしなかった せいで、ほんばんで しっぱいしました。(Gara-gara tidak latihan, saya gagal saat tampil.)
7. 明るい うちに 帰りましょう。(Pulanglah selagi masih terang.)
8. わかい うちに、いろいろな くにへ 行きたいです。(Selagi muda, saya ingin pergi ke berbagai negara.)

## Latihan

1. Pilih yang tepat: 先生の(おかげで / せいで)、試験に ごうかくできました。
2. Pilih yang tepat: たいふうの(おかげで / せいで)、飛行機が とまりました。
3. Pilih yang tepat: 毎日 勉強した(おかげで / せいで)、せいせきが あがった。
4. Pilih yang tepat: ねぶそくの(おかげで / せいで)、あたまが いたい。
5. Isi dengan 〜うちに: わすれない______、メモしておきます。
6. Isi dengan 〜うちに: ______うちに、旅行に 行きたいです。(bebas: kondisi yang akan berubah)
7. Terjemahkan: "Gara-gara hujan, pertandingan dibatalkan." → ______
8. Betulkan kalimat yang salah: かれの おかげで、けがを しました。

## Tips / pola penting

- Aturan emas: hasil baik → おかげで, hasil buruk → せいで. Tidak ada pengecualian. Selalu cek hasil kalimatnya dulu sebelum memilih.
- 〜おかげで sering diikuti terima kasih; 〜せいで diikuti keluhan.
- 〜うちに memakai bentuk bukan lampau: 明るいうちに, わすれないうちに.

## Ringkasan

- 〜おかげで = kata benda + の / bentuk lampau + おかげで; "berkat", selalu untuk hasil positif.
- 〜せいで = pola sama + せいで; "gara-gara", selalu untuk hasil negatif.
- Pasangan kontras wajib hafal: れんしゅうしたおかげでせいこう / れんしゅうしなかったせいでしっぱい.
- 〜うちに = bentuk bukan lampau + うちに; "selagi / mumpung" sebelum keadaan berubah.
- Kanji: 閥 (faksi), 拘 (menahan), 逮 (menangkap), 訴 (menggugat), 却 (menolak), 審 (memeriksa), 枠 (batasan).

## Tugas & catatan SRS

Tugas: tulis 2 pasangan kalimat kontras (satu kejadian baik dengan おかげで, satu kejadian buruk dengan せいで, dari pengalamanmu sendiri) dan 2 kalimat 〜うちに tentang rencanamu. Masukkan ke deck SRS: 〜おかげで, 〜せいで, 〜うちに, かんしゃ, どりょく, 派閥, そしょう, きゃっか.
