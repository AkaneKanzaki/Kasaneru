## Lesson goals

After this lesson, you can run a half-mock: a timed 70-minute practice block covering vocabulary, grammar, and reading. You know its preparation checklist, the pacing rules for each section, and how to review the results so they become material for improvement.

## Explanation

**Half-mock** is a half simulation: a timed 70-minute block for the first three N3 areas — もじ・ごい (20 minutes), ぶんぽう (25 minutes), どっかい (25 minutes). This is a condensed practice version of the official allocation; its purpose is to train pacing and find error patterns before the full mock. The questions come from the app's question bank — this lesson is only the guide.

**Preparation checklist:** a visible timer, paper and pencil, a quiet room, a question set you've never done before, and a written target score. Don't start when you're tired.

**Pacing rules (while working):** start with the questions you've mastered most; max 60 seconds per vocabulary question and 90 seconds per grammar question; stuck longer than that → mark and move on. For reading, apply the L41–L42 techniques: read the questions first, don't reread the whole text.

**How to review (after finishing):** score each area, read the かいせつ for wrong questions AND right-but-unsure questions, then write one log line per problem question: area | question type | cause. Example: どっかい | main idea | picking a detail as the answer.

## Example sentences

| Block | Time | Rules |
|---|---|---|
| もじ・ごい | 20 minutes | Max 60 seconds/question; stuck → mark, move on |
| ぶんぽう | 25 minutes | Read the sentence to the end first; max 90 seconds/question |
| どっかい | 25 minutes | Questions first (L41–L42); last 5 minutes みなおし |

Example of a good error log:
- ぶんぽう | 〜ばかりか vs 〜どころか | memorized the meaning, wrong direction
- どっかい | idea vs fact | quoting a character's words as fact

## Practice

1. What is the time allocation for each block in the 70-minute half-mock? For which areas?
2. You're stuck on one grammar question for 2 minutes. What should you do according to the pacing rules?
3. Besides wrong questions, what other questions must you read the explanation for? Why?
4. Write the one-line error log format plus one example of your own.
5. When is the right time to schedule a half-mock this week? Explain your reasoning.

### Answer key

1. もじ・ごい 20 minutes, ぶんぽう 25 minutes, どっかい 25 minutes (70 minutes total).
2. Mark and move on — the limit is 90 seconds per grammar question. Come back during みなおし time if there's time.
3. Right-but-unsure questions — "right by guessing" can fail in the real exam, so the pattern still needs fixing.
4. area | question type | cause. Example: ごい | similar-sounding words | didn't note the accent-based meaning differences.
5. Answers vary; the correct one: on the day you're freshest (not late at night), with at least a one-day gap after heavy practice.

## Tips / key patterns

- Don't use a question set you've already done — memorized questions ruin the measurement.
- The working order may be changed: if reading is your strength, start there to build confidence.
- After the review, celebrate a little (even a mini 宴会 with friends) — your brain needs a break before the next session.

## Summary

- Half-mock = 70-minute block: vocabulary 20', grammar 25', reading 25'.
- Pacing rules: 60 seconds (vocabulary) / 90 seconds (grammar); stuck → mark and move on.
- Review: score per area + かいせつ for wrong and unsure questions + one log line per question.
- The error log is the raw material for L47.
- Kanji checklist (strokes, read without hesitation): 宴（宴会・えんかい）・替（替える・かえる）・換（こうかん・こうかん）・模（もぎしけん・もぎしけん）。
