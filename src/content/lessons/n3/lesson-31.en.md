## Lesson goals

After this lesson, you can read a short text (たんぶん) of about 150–250 characters and find the two things most often asked at N3: the writer's purpose in writing the text and its main idea. You'll also master 〜につれて and 〜にしたがって for two changes that proceed side by side ("along with ...").

## Explanation

### The patterns 〜につれて・〜にしたがって

Both mean "along with ..." for two changes proceeding in tandem.

- どうしじしょけい + につれて / にしたがって
- めいし + につれて / にしたがって

Examples:

- 年をとるにつれて、からだがよわくなる。(As one gets older, the body weakens.)
- じんこうが増えるにしたがって、ごみも増える。(As the population grows, garbage increases too.)

Nuance difference: につれて is for natural, gradual changes; にしたがって is more formal and appears more often in written text. Neither is used for a one-time sudden event.

### Reading strategy for たんぶん: purpose and main idea

1. Read the first sentence (topic) and the last sentence (conclusion). The main idea is almost always in one of them.
2. Look for markers of the writer's opinion at the end of the text: である, のだ, べきだ.
3. Skip the example details in the middle of the text when hunting for the main idea. Examples are only supporting, not the core.

All ten kanji in this lesson are animal names: 猿 (さる = monkey), 熊 (くま = bear), 虎 (とら = tiger), 兎 (うさぎ = rabbit), 蛇 (へび = snake), 蝶 (ちょう = butterfly), 蜂 (はち = bee), 蚊 (か = mosquito), 鯨 (くじら = whale), 亀 (かめ = turtle).

## Example sentences

*Register: であるたい — formal written language (essays/articles).*

> ジャカルタのじんこうが増えるにつれて、うみべのごみも増えている。ごみが増えるにしたがって、亀やさかながごみをえさとまちがえてたべてしまうことが多くなったのである。えさをさがす蝶や蜂がすむはやしも、いえが増えるにつれてへっている。蛇や蚊が人のいえに近づくことも多くなった。ごみをへらすことが、いきものの命をまもるだいいっぽである。

**Comprehension questions**

1. このぶんしょうはなんのために書かかれたか。Answer in English.
2. ごみが増えるにしたがって、なにが多くなったか。
3. ひっしゃがいちばんいいたいことはなにか。Answer in English.
4. つぎのぶんはただしいか、ただしくないか。「蝶や蜂がすむはやしは増えている。」

### Answer key

1. To explain that increasing garbage endangers living creatures, and to urge readers to reduce it.
2. 亀やさかながごみをえさとまちがえてたべてしまうことが多くなった。
3. ごみをへらすことが、いきものの命をまもるだいいっぽである。
4. ただしくない。はやしはへっていると書いてある。

## Practice

1. たんぶんのようてんをさがすとき、まず読むべきなのはどこか。
a. まん中のれい b. はじめとおわりのぶん c. 出てくるかんじのよみかた
2. 「〜につれて」と「〜にしたがって」のちがいでただしいのはどれか。
a. いみがぜんぜんちがう b. どちらも「せいりんで」のいみだが、にしたがってのほうがフォーマルでかきことばてきだ c. につれてはいっかいだけの出来事に使う
3. Fill in with the correct pattern: 雨が____、みちがこんでくる。(降る)
4. Fill in with the correct pattern: としを____、からだのちょうしがかわる。(とる)
5. Translate into Japanese: "As れんしゅう increases, results improve."
6. From the reading: 蛇や蚊について、ひっしゃはなにといっているか。Answer in English.
7. From the reading: はやしがへっているりゆうはなにか。Answer in English.
8. Which sentence uses the pattern INCORRECTLY?
a. 年をとるにつれて、しわが増える。b. 昨日につれて、雨が降った。c. 景気がよくなるにしたがって、店が増える。

### Answer key

1. b
2. b
3. 降るにつれて
4. とるにしたがって（とるにつれて is also correct）
5. れんしゅうが増えるにつれて、結果がよくなる。
6. 蛇や蚊が人のいえに近づくことが多くなったといっている。
7. いえが増えるにつれて、はやしがへっているから。
8. b（「昨日につれて」はおかしい。いっかいだけの出来事には使えない）

## Tips / key patterns

- Common mistake: using 〜につれて for a one-time event ("yesterday ..."). This pattern is only for gradual changes that proceed together.
- Distinguish facts (増えている) from the writer's opinion (〜べきである). "Purpose of the text" questions ask about the opinion or appeal, not just the facts.

## Summary

- 〜につれて / 〜にしたがって = "along with ...", for two gradual changes that proceed together.
- にしたがって is more formal and characteristic of written language.
- たんぶん strategy: read the first and last sentences, look for the markers である・のだ・べきだ.
- Kanji: 猿 熊 虎 兎 蛇 蝶 蜂 蚊 鯨 亀 (animal names).
