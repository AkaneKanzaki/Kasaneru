## Lesson goals

After this lesson, you can express strong refusal with the rhetorical N2 patterns 〜ものか and 〜もんか ("as if…!"). This strong, spoken pattern is used to refuse, deny, or assert determination.

## Explanation

**〜ものか / 〜もんか (pattern 18).** The formula: dictionary-form verb + ものか (or もんか, which is more casual). Means "as if…!" — a very strong rhetorical refusal.

- 忘れる ものか。(As if I'd forget!)

Note the tone: this pattern is emotional and spoken. Don't use it in formal texts or to a superior — it sounds rude and defiant.

This pattern can also attach to adjectives and nouns: 「安い ものか」(as if it's cheap!). But the most frequently tested form is dictionary-form verb + ものか.

Distinguish from 〜ものだ (N3) expressing advice ("〜should"): 「諦める ものでは ない」(you shouldn't give up) is totally different from 「諦める ものか」(as if I'd give up!).

The six kanji in this lesson: 購 (こう = to buy, e.g. 購買), 販 (はん = to sell, e.g. 販売), 質 (しつ = quality, e.g. 品質), 量 (りょう = quantity, e.g. 大量), 簡 (かん = simple, e.g. 簡素), 幣 (へい = money, e.g. 紙幣).

## Example sentences

1. 〔話し言葉〕 こんな 粗悪品を 買う ものか。(As if I'd buy such a shoddy product!)
2. 〔話し言葉〕 欠陥品だと 知ってて 売る もんか。(As if I'd sell it knowing it's defective!)
3. 〔話し言葉〕 値上げの 理由も 言わずに 納得できる ものか。(As if I could accept it without being told the reason for the price hike!)
4. 〔話し言葉〕 ブディは 「こんな 苦情に 屈する ものか」と 言った。(Budi said, "As if I'd submit to a complaint like this.")
5. 〔話し言葉〕 シンタは 涙を こらえて 「諦める もんか」と つぶやいた。(Sinta held back her tears and muttered, "As if I'd give up.")
6. 〔話し言葉〕 偽物の 紙幣を つかまされる ものか。(As if I'd let myself be cheated with counterfeit bills!)
7. 〔話し言葉〕 大量の 返品が 来ても 怯む ものか。(As if I'd flinch even if a flood of returns came!)

## Practice

2. Fill in with the correct pattern: こんな 品物を 買う___。
3. Choose the casual one: (ものか / もんか)。
4. Distinguish the meanings: 諦めるものではない means ______, 諦めるものか means ______. (advice "should not" / emotional refusal "as if")
5. Translate into Japanese: "As if I'd forget!" → ______
6. True or false: using 〜ものか in a formal email to a superior → ______ (true/false, explain)
7. Form 〜ものか from an adjective: 安い → ______

### Answer key

1. ものか
2. ものか
3. もんか
4. 諦めるものではない means advice "should not give up", 諦めるものか means emotional refusal "as if I'd give up!"
5. 忘れる ものか。
6. false — 〜ものか is strong and spoken in tone, not appropriate for formal texts or to a superior
7. 安いものか

## Tips / key patterns

- The verb is always in dictionary form: 買うものか, 忘れるものか. The ます form (×買いますものか) is wrong.
- The pair often pitted against each other in exams: 〜ものだ (advice, gentle) vs 〜ものか (refusal, harsh). A single か changes the meaning totally.

## Summary

- 〜ものか / 〜もんか (dictionary-form verb +): "as if…!" — a very strong rhetorical refusal.
- もんか is more casual than ものか; both are spoken and emotional, not for formal situations.
- Totally different from 〜ものだ (N3): gentle-toned advice or recollection.
- Kanji: 購 (to buy), 販 (to sell), 質 (quality), 量 (quantity), 簡 (simple), 幣 (money).
