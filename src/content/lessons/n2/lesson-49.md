## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa memakai set contoh soal resmi N2 dari jlpt.jp sebagai JANGKAR untuk mengkalibrasi skor mock aplikasimu: cara pakai (tanpa mereproduksi soal resmi), cara baca selisih, dan kapan waktu terbaiknya.

## Penjelasan

**Jangkar resmi** = set contoh soal N2 jlpt.jp — satu-satunya materi yang DIJAMIN mencerminkan ujian asli. Semua mock lain adalah ESTIMASI.

**5 langkah:**

1. Unduh set N2 dari jlpt.jp; jangan dibuka sebelum hari eksekusi.
2. Kerjakan mode Real penuh: 155 menit, listening sekali putar (pakai audio resmi bila ada).
3. Nilai dengan kunci resmi, per seksi: 言語知識 /60, 読解 /60, 聴解 /60.
4. Bandingkan dengan rata-rata 2–3 mock aplikasimu (estimasi).
5. Isi tabel kalibrasi, tentukan aksi.

**Membaca selisih (ESTIMASI):** ≤10 = kalibrasi baik. App >15 LEBIH TINGGI → NAIKKAN target (bidik 105–110). App >15 LEBIH RENDAH → fokus tipe yang jatuh di set resmi. Selalu per seksi: selisih terbesar = prioritas (klinik L47).

**Kapan:** 3–4 minggu sebelum ujian. Jangan di awal — peluru kalibrasi hanya satu.

**Etika:** jangan salin soal resmi ke catatan/SRS; cukup rujuk nomornya ("set resmi N2, 読解 soal 12").

## Contoh kalimat

**Contoh tabel kalibrasi terisi (fiktif):**

| Seksi (/60) | Mock app rata-rata (est.) | Set resmi | Selisih | Tafsir |
|---|---|---|---|---|
| 言語知識 | 38 | 33 | −5 | kalibrasi OK |
| 読解 | 40 | 28 | −12 | bank app terasa lebih mudah |
| 聴解 | 35 | 36 | +1 | kalibrasi OK |
| Total (/180) | 113 | 97 | −16 | naikkan target latihan ke ~105–110 |

Keputusan: total masih ≥90 (est.), tapi selisih 16 → target aman 105+. Prioritas: 読解 → klinik L47.

## Latihan

1. Apa "jangkar resmi"? Mengapa hanya soal resmi yang valid sebagai patokan?
2. Sebutkan lima langkah memakai set resmi untuk kalibrasi.
3. Hasil: rata-rata mock aplikasi 105, set resmi 88. Apa tafsir dan aksinya?
4. Mengapa kalibrasi harus per seksi?
5. Kapan waktu terbaik memakai jangkar resmi? Mengapa tidak di awal persiapan?

### Kunci jawaban

1. Set contoh soal resmi jlpt.jp; hanya materi resmi yang dijamin mencerminkan ujian asli.
2. Unduh tanpa membuka → kerjakan mode Real 155 menit → nilai per seksi dengan kunci resmi → bandingkan dengan rata-rata mock app → isi tabel kalibrasi dan tentukan aksi.
3. Selisih 17 (>15): bank soal lebih mudah → naikkan target (~105).
4. Total bisa menutupi seksi yang jebol; selisih terbesar = prioritas.
5. 3–4 minggu sebelum ujian; di awal = membuang satu-satunya alat ukur valid.

## Tips / pola penting

- Satu set = satu kali pakai. Jangan "berlatih" dengannya berulang-ulang; hafal soal merusak fungsinya.
- Audio resmi persis seperti ujian — dengarkan sekali lagi saat review.
- Tanpa audio resmi, pakai audio aplikasi — tapi catat kalibrasi listening-mu kurang valid.
- Setelah kalibrasi, tulis target barumu di tempat terlihat: "Target latihan: 105 (est.), bukan 90."

## Ringkasan

- Jangkar = set contoh soal N2 jlpt.jp; satu-satunya patokan kesulitan yang dijamin.
- 5 langkah: unduh → mode Real → nilai per seksi → bandingkan → tabel kalibrasi.
- Selisih ≤10 = OK; app >15 tinggi = naikkan target; app >15 rendah = adaptasi format. Selalu per seksi (/60).
- Waktu: 3–4 minggu sebelum ujian; jangan reproduksi soal resmi.

## Tugas & catatan SRS

Pastikan kamu tahu cara mengakses set contoh soal N2 di jlpt.jp (jangan dikerjakan bila ujian >4 minggu); tulis tanggal rencanamu di kalender. Masukkan ke deck SRS: 公式、基準、目安、照らし合わせる、乖離、公開する.
