## Lesson goals

After this lesson, you can describe unspoken attitudes or speech — "as if saying ..." — with the pattern 〜とばかり. You can also firmly distinguish it from 〜んばかり (L19): 〜とばかり always implies words directed at someone else. This lesson introduces no new kanji.

## Explanation

**1. Form and meaning.** The pattern: a quotation (command, utterance, or thought) + とばかり(に). It means "as if saying ..." — describing an attitude or action that **implies unspoken words**, always directed at someone else.

- 「帰れ」とばかりに戸を閉めた (as if saying "go home", he closed the door)
- 出て行けとばかりの態度 (an attitude as if saying "get out")

The quotation before it is usually a command or prohibition: 帰れ, 出て行け, 座れ, 早くしろ, もう結構です. The quotation marks 「」 may be written or omitted.

**2. Its three forms** — just like 〜んばかり:

- 〜とばかりに = adverbial: 「帰れ」とばかりに戸を閉めた.
- 〜とばかりの = attributive: 出て行けとばかりの態度.
- 〜とばかりだ = predicate: その視線は「帰れ」とばかりだ.

**3. Difference from 〜んばかり (L19).** This is the point most often tested:

| | 〜んばかり | 〜とばかり |
| Describes | a state on the verge of an act | unspoken words/attitude |
| Example | 泣かんばかり (almost in tears) | 「帰れ」とばかり (as if saying "go home") |
| Direction | at the state itself | at someone else |

Quick test: if you can insert the word "saying", use とばかり. 「帰れ」とばかりに = "as if SAYING go home". 泣かんばかり can't be tested that way — it is purely a state.

## Example sentences

1. 〔文語・である体〕 「帰れ」とばかりに、主人は戸を閉めた。(As if saying "go home", the host closed the door.)
2. 〔文語・である体〕 出て行けとばかりの態度に、ブディさんは傷ついた。(Budi was hurt by the attitude as if saying "get out".)
3. 〔話し言葉〕 「早くしろ」とばかりに、シンタさんは時計を見た。(As if saying "hurry up", Sinta glanced at the clock.)
4. 〔文語・である体〕 無言のまま、座れとばかりに椅子を示した。(Without a single word, he pointed at the chair as if saying "sit down".)
5. 〔ビジネス〕 「もう結構です」とばかりに、相手は話を打ち切った。(As if saying "that's enough", the other party cut the conversation short.)
6. 〔文語・である体〕 文句があるなら言えとばかりに、彼はうでを組んだ。(As if saying "if you have a complaint, say it", he folded his arms.)

## Practice

1. Fill in with the correct pattern: 「帰れ」＿＿＿、戸を閉めた。
2. Fill in with the correct pattern: 出て行け＿＿＿態度に傷ついた。
3. Choose the correct one for "as if saying hurry up": (早くしろとばかりに / 早くしそうなばかりに)
4. Choose the correct pattern: 泣か＿＿＿顔 (a face like about to cry — describes a state)
5. Choose the correct pattern: 「だまれ」＿＿＿にらんだ (as if saying "be quiet" — implies unspoken words)
6. Translate into Japanese: "As if saying sit down, he pointed at the chair." → ______
7. True or false: 〜とばかり and 〜んばかり are interchangeable without changing the meaning. → ______

### Answer key

1. とばかりに
2. とばかりの
3. 早くしろとばかりに
4. んばかりの (L19 pattern)
5. とばかりに
6. 「座れ」とばかりに、椅子を示した。
7. False (んばかり = state; とばかり = unspoken words directed at someone else)

## Tips / key patterns

- The quotation before とばかり is usually a command/prohibition: 帰れ, 出て行け, 座れ, だまれ, 早くしろ.
- The "saying" test: if the meaning is "as if SAYING ...", the answer is とばかり; if it's "almost/the state is like ...", the answer is んばかり.
- とばかりに modifies verbs; とばかりの modifies nouns — parallel to 〜んばかり.
- This pattern is literary in tone; in the exam it is often paired with 〜んばかり as a distractor.

## Summary

- Quotation + とばかり(に/の/だ) = "as if saying ...", unspoken words/attitude.
- Always directed at someone else with a speech nuance — different from 〜んばかり, which is purely a state.
- The quotations are usually commands: 帰れ, 出て行け, 座れ.
- Quick test: can insert "saying" → とばかり.
- This lesson introduces no new kanji.
