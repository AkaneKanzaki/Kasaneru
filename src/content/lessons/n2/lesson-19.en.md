## Lesson goals

After this lesson, you can describe a state on the verge of happening — "as if about to ..." — with the literary pattern 〜んばかり. You can also choose the right form: 〜んばかりに (adverbial), 〜んばかりだ (predicate), and 〜んばかりの (attributive).

## Explanation

**1. Form and meaning.** The pattern: verb negative form without ない + んばかり. It means "as if about to ..." — describing a state **on the verge of** an action.

- 泣かんばかりに訴えた (pleaded as if about to cry)
- 今にも降らんばかりの空 (a sky as if about to rain)

How to make the "negative form without ない": 泣かない → 泣か, 降らない → 降ら, する → せ (せんばかり), 来る → 来 (来んばかり/こんばかり).

**2. Its three forms.**

- 〜んばかりに = adverbial (modifies a verb): 泣かんばかりに訴えた.
- 〜んばかりだ = predicate: 割れんばかりの拍手だった → 拍手は割れんばかりだ.
- 〜んばかりの = attributive (modifies a noun): 降らんばかりの空.

**3. Nuance.** This is a poetic literary pattern, often appearing in novels and news to describe dramatic scenes: 今にも (any moment) often accompanies it. This pattern describes **a state**, not speech — for "as if saying", wait for the next lesson (〜とばかり). This lesson introduces no new kanji.

## Example sentences

1. 〔文語・である体〕 シンタさんは泣かんばかりに事情を訴えた。(Sinta explained her situation as if about to cry.)
2. 〔文語・である体〕 空は今にも降らんばかりに曇っている。(The sky is cloudy as if it could rain any moment.)
3. 〔文語・である体〕 ブディさんはこぶしを握り、殴らんばかりの勢いだった。(Budi clenched his fists with a force as if about to punch.)
4. 〔話し言葉〕 あの子、泣かんばかりの顔してたよ。(That kid had a face like he was about to cry.)
5. 〔文語・である体〕 観客は総立ちとなり、割れんばかりの拍手だった。(The audience all stood up; the applause was as if it would burst.)
6. 〔ビジネス〕 倒れんばかりの忙しさですが、何とか頑張ります。(I'm so busy it's as if I might collapse, but I'll do my best somehow.)

1. 泣かんばかり
2. せんばかり
3. んばかりに
4. んばかりの
5. んばかりに
6. 空は今にも降らんばかりに曇っている。
7. False (that's the function of 〜とばかり in L20; 〜んばかり is for states)

## Tips / key patterns

- Remember the formula: negative form, drop ない, attach んばかり. Practice with irregular verbs: せんばかり, 来んばかり.
- んばかりに modifies verbs; んばかりの modifies nouns; んばかりだ becomes the predicate.
- The faithful companion of this pattern is 今にも ("any moment"): 今にも降らんばかり, 今にも泣き出さんばかり.
- This is a pattern of states/appearances. If what is described is "unspoken speech", that's 〜とばかり (next lesson).

## Summary

- V(negative without ない) + んばかり = "as if about to ...", a state on the verge of an action.
- Three forms: 〜んばかりに (adverbial), 〜んばかりの (attributive), 〜んばかりだ (predicate).
- Irregular: する → せんばかり, 来る → 来んばかり.
- Often together with 今にも; literary/dramatic tone.
