## Lesson goals

After this lesson, you will be able to turn mock wrong answers into a diagnosis: grouping errors per strand, classifying their causes into four categories, and determining a specific fix action per category.

## Explanation

**Step 1 — gather the material.** Take the mock error log (L46), at least 15 lines. Without a log, there is no diagnosis.

**Step 2 — classify.** Each error goes into ONE category, then group per strand (goi/bunpou/dokkai/choukai):

- (a) DIDN'T KNOW — word/pattern never learned before.
- (b) CONFUSED — two similar things mixed up (検討 vs 検査).
- (c) WRONG STRATEGY — wrong order/timing, or misread the question instructions.
- (d) CARELESS — knew it, but misread options / rushed.

**Step 3 — determine the action per category:**

| Category | Action |
|---|---|
| Goi: didn't know | SRS + original example sentences |
| Goi: confused | A vs B comparison cards |
| Bunpou: didn't know | re-read the lesson + 10-question drill |
| Bunpou: confused | 15-question paired-pattern drill |
| Dokkai: wrong strategy | redo L41–L43 timed |
| Dokkai: ran out of time | daily 90-second scan drill |
| Choukai: missed hearing | focus drill + 4K notes |
| Choukai: misunderstood | causal vocab → SRS |
| Careless (all strands) | checklist: read ALL options |

**Step 4 — prioritize** (frequency × impact); work the top 3 this week.

## Example sentences

**Template + filled example (fictional)** — copy this format for each mock:

| No | Section | Question type | Cause category | Fix action |
|---|---|---|---|---|
| 1 | Goi | similar words | confused: 検討 vs 検査 | comparison cards + SRS |
| 2 | Bunpou | 〜ざるを得ない | confused: 〜ないではいられない | 15-question paired-pattern drill |
| 3 | Dokkai | 主張理解 | wrong strategy: chose a detail | redo L41 timed |
| 4 | Choukai | 課題理解 | missed the final decision while listening | 4K drill, wait for the dialog's end |
| 5 | Goi | vocabulary | careless: option d not read | checklist: read all options |

Priority in this example: no. 2 and 3, then no. 4.

## Practice

1. Name the four error-cause categories + one example of each.
2. "Confusing 〜ざるを得ない/〜ないではいられない": which strand, category, and action?
3. What's the difference in handling "missed hearing" vs "misunderstood"?
4. How do you determine priorities from the analysis table?
5. Take 5 lines from your mock log, classify them into the table, and write the actions.

### Answer key

1. (a) didn't know; (b) confused; (c) wrong strategy; (d) careless.
2. Bunpou, confused → the 15-question paired-pattern drill.
3. "Missed hearing" → focus drill + 4K notes; "misunderstood" → causal vocab into SRS.
4. Sort by frequency × impact; work the top 3 this week.
5. Correct example: each line has section, question type, ONE category, and ONE specific action (not "study more").

## Tips / key patterns

- "Study more" is not an action; a good action says WHAT and HOW MUCH.
- "Confused" is a gold mine: one comparison card fixes a dozen questions at once.
- Fill the table at least 2 hours after the mock — don't diagnose while emotional.
- Keep all tables — trends between mocks ("careless down 6→2") are proof of progress beyond scores.

## Summary

- Material = log of ≥15 lines; no log, no diagnosis.
- Four categories: didn't know, confused, wrong strategy, careless — each has a specific action.
- Priority = frequency × impact; work the top 3 per week.
- Good actions say what and how much.
