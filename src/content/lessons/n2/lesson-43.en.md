## Lesson goals

After this lesson, you will be able to handle the 統合理解 question type: reading TWO short texts about one topic, comparing each author's stance and reasons, then answering questions about similarities, differences, and synthesis.

## Explanation

A five-step strategy for two texts:

**1. Read text A: note STANCE + 2 REASONS.** One line is enough: "A = 賛成：通勤時間ゼロ、集中できる".

**2. Read text B the same way.** One line: "B = 反対：対面が減る、境目が曖昧".

**3. Make a mini comparison table.** In your head or on scrap paper:

| | Text A | Text B |
|---|---|---|
| Stance | 賛成 | 反対 |
| Core reason | 効率・生産性が上がる | 長期的には生産性が下がるおそれ |
| Concession | 運動不足という課題もある | 柔軟さは大切だ |

**4. Answer integration questions by type.** (a) SIMILARITY → find what BOTH agree on; often hidden in concession sentences (たしかに〜が, もちろん〜). (b) DIFFERENCE → compare the core reasons, not details. (c) SYNTHESIS → combine both sides; an answer siding with only one text is usually wrong.

**5. Watch out for the one-text trap.** An option that is 100% correct for text A but contradicts text B is a classic distractor for "both" questions.

## Example sentences

**Text A** 〔意見文〕

> 在宅勤務に賛成だ。まず、通勤時間がなくなるのは大きい。私の場合、往復で二時間かかっていた。その二時間を仕事や家族との時間に使えるようになった。通勤ラッシュのストレスから解放されたことも大きい。次に、集中できる環境を自分で作れる。オフィスでは話し声や電話で集中が切れることが多かったが、家では静かに作業できる。昼休みに家族と昼食を取れるようになった。もちろん、課題もある。運動不足になりがちだ。しかし、昼休みに散歩する習慣をつければ解決できる。在宅勤務は、工夫と努力しだいで生産性を上げる働き方だと考える。

**Text B** 〔意見文・である体〕

> 在宅勤務には反対である。理由は二つある。一つ目は、対面のコミュニケーションが減ることである。ちょっとした相談や雑談から生まれるアイデアは、画面越しでは生まれにくい。二つ目は、仕事と生活の境目が曖昧になることである。残業が増え、休みの日もメールの返事を気にしてしまう人が多い。効率が上がるという意見もあるが、長い目で見れば、孤独や疲れが生産性を下げるおそれがある。もちろん、敢えてオフィスに出社し、対面の交流を大切にする社員もいる。働き方の柔軟さは大切だが、在宅勤務の拡大には慎重であるべきだ。

**Applying the strategy:**

- Map A: 賛成 — reasons: 通勤ゼロ, 集中できる; concession: もちろん、課題もある（運動不足）.
- Map B: 反対 — reasons: 対面が減る, 境目が曖昧; concession: 柔軟さは大切だ.
- What both share: BOTH acknowledge a positive side and problems — A acknowledges 課題, B acknowledges 柔軟さは大切. This is the material for "共通する考え" answers.

## Practice

Read both texts in one go (5 minutes total target), make a one-line map of each text, then answer.

1. 二つの文章に共通する考えはどれか。
a. 在宅勤務には何の問題もない
b. 在宅勤務には利点と課題の両方がある
c. 在宅勤務は生産性を下げる
d. 在宅勤務はやめるべきだ

2. AとBの意見が最も対立している点は何か。
a. 通勤時間の長さ
b. 在宅勤務が生産性に与える影響
c. 運動不足の解決方法
d. 残業があるかどうか

3. Answer in English: according to text B, why can text A's efficiency claim be misleading in the long term?

### Answer key

1. b — A acknowledges 課題 (運動不足), B acknowledges 柔軟さは大切; both see the positive side and the problems. Options a/c/d only side with one text.
2. b — A: 工夫しだいで生産性を上げる; B: 長い目で見れば生産性を下げるおそれ. This is the crux of the debate. Options a/c/d are details, not the crux.
3. Because face-to-face communication decreases (ideas from casual chats are hard to spark through a screen) and the work–life boundary blurs (overtime increases, days off still mean thinking about email) — loneliness and fatigue ultimately lower productivity.

## Tips / key patterns

- Don't answer integration questions from memory of one text alone; always cross-check with the other text's map.
- Concession sentences (もちろん〜, たしかに〜が, 〜は大切だが) are gold mines for similarity questions — mark them while reading.
- The correct "both" option is almost always balanced in tone; extreme options are usually distractors.
- Time target: two texts ±250 characters + 3 questions = 10 minutes total.

## Summary

- Each text's map = one line: stance + 2 reasons + 1 concession.
- Similarity → look in concession sentences; difference → compare core reasons.
- Synthesis = combine both sides, not pick one text.
- Watch out for options correct for one text but wrong for the combination.
- A 3-column mini table speeds up all integration question types.

## Tasks & SRS notes

Re-read both texts, write each one's one-line map without peeking, then compare. Find another topic (e.g. "online shopping vs physical stores"), write two short opposing paragraphs (±150 characters each side) as mapping practice. Add to your SRS deck: 賛成、反対、境目、曖昧だ、両立する、生産性、努力. Kanji checklist (stroke order, read without hesitation): 努（努力・どりょく）・敢（敢えて・あえて）.
