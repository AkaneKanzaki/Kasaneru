## Lesson goals

After this lesson, you will be able to use the official N2 sample-question set from jlpt.jp as an ANCHOR to calibrate your app's mock scores: how to use it (without reproducing official questions), how to read the gap, and when the best time is.

## Explanation

**Official anchor** = the jlpt.jp N2 sample-question set — the only material GUARANTEED to reflect the real exam. All other mocks are ESTIMATES.

**5 steps:**

1. Download the N2 set from jlpt.jp; don't open it before execution day.
2. Do it in full Real mode: 155 minutes, listening played once (use the official audio if available).
3. Score it with the official key, per section: 言語知識 /60, 読解 /60, 聴解 /60.
4. Compare with the average of your 2–3 app mocks (estimates).
5. Fill in the calibration table, determine actions.

**Reading the gap (ESTIMATE):** ≤10 = good calibration. App >15 HIGHER → RAISE the target (aim for 105–110). App >15 LOWER → focus on the types that dropped in the official set. Always per section: the biggest gap = priority (L47 clinic).

**When:** 3–4 weeks before the exam. Not at the start — the calibration bullet is single-use.

**Ethics:** don't copy official questions into notes/SRS; just reference their number ("official N2 set, 読解 question 12").

## Practice

1. What is the "official anchor"? Why are only official questions valid as a benchmark?
2. Name the five steps for using the official set for calibration.
3. Result: app mock average 105, official set 88. What's the interpretation and action?
4. Why must calibration be per section?
5. When is the best time to use the official anchor? Why not at the start of preparation?

### Answer key

1. The official jlpt.jp sample-question set; only official material is guaranteed to reflect the real exam.
2. Download without opening → do it in 155-minute Real mode → score per section with the official key → compare with the app mock average → fill in the calibration table and determine actions.
3. Gap of 17 (>15): the question bank is easier → raise the target (~105).
4. The total can hide a failed section; the biggest gap = priority.
5. 3–4 weeks before the exam; at the start = wasting the only valid measuring tool.

## Tips / key patterns

- One set = one use. Don't "practice" with it repeatedly; memorized questions ruin its function.
- The official audio is exactly like the exam — listen to it once more during review.
- Without the official audio, use the app's audio — but note your listening calibration is less valid.
- After calibration, write your new target somewhere visible: "Practice target: 105 (est.), not 90."

## Summary

- Anchor = the jlpt.jp N2 sample-question set; the only guaranteed difficulty benchmark.
- 5 steps: download → Real mode → score per section → compare → calibration table.
- Gap ≤10 = OK; app >15 high = raise target; app >15 low = adapt to the format. Always per section (/60).
- Timing: 3–4 weeks before the exam; don't reproduce official questions.
