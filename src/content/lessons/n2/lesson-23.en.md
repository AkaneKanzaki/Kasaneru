## Lesson goals

After this lesson, you can use 〜そばから to express "as soon as X happens, Y follows right away" — usually with a nuance of wasted effort or annoyance. You can also distinguish it from 〜やいなや / 〜が早いか (N3), which sound neutral.

## Explanation

**1. Form.** Verb dictionary form + そばから. Examples: 聞くそばから, 読むそばから, 片付けるそばから. The word そば itself means "side / beside", so the pattern literally means "from the side of X…".

**2. Meaning: "as soon as… right away…".** As soon as event X is over, event Y follows immediately — and usually Y undoes or cancels out the result of X. This is the source of its wasted-effort nuance.

- 聞くそばから忘れる。(I forget as soon as I hear it — the memorizing is wasted.)
- 片付けるそばから散らかる。(It gets messy again as soon as I tidy it up.)

**3. Negative nuance.** Unlike 〜やいなや / 〜が早いか (N3), which are neutral and one-off, 〜そばから carries the speaker's annoyance and often describes repeated events: every time X, always Y. That makes it perfect for complaints.

**4. This lesson's kanji (11).** 奸 (かん = wicked cunning), 佞 (ねい = flatterer, e.g. 佞言), 諂 (へつらう = to flatter), 諛 (ゆ = flattery, e.g. 諂諛), 媚 (こびる = to fawn), 傲 (おごる = arrogant, e.g. 傲慢), 慢 (まん = haughty, e.g. 慢心), 倨 (おごる = haughty, e.g. 倨傲), 驕 (おごる = arrogant; to treat), 奢 (おごる = to treat lavishly), 僭 (せん = presumptuous, e.g. 僭越).

## Example sentences

1. 〔話し言葉〕 シンタさんは聞くそばから忘れてしまう。(Sinta forgets as soon as she hears it.)
2. 〔文語・である体〕 片付けるそばから散らかるので、子どもの部屋はちっともきれいにならない。(Since it gets messy again as soon as it's tidied up, the child's room never becomes clean at all.)
3. 〔話し言葉〕 ブディさんは覚えるそばから忘れるので、単語帳が手放せない。(Budi forgets as soon as he memorizes, so he can't let go of his vocabulary notebook.)
4. 〔文語・である体〕 稼ぐそばから使ってしまう彼の財布は、いつも空である。(His wallet, which gets emptied as soon as he earns money, is always empty.)
5. 〔ビジネス〕 報告するそばから新しい指示が来るので、対応が追いつきません。(Since new instructions arrive as soon as I report, I can't keep up with handling them.)
6. 〔話し言葉〕 教えるそばから忘れる生徒に、先生も苦笑いするしかなかった。(With students who forget as soon as they're taught, the teacher could only smile wryly.)

## Practice

1. Change to the 〜そばから pattern: 聞く → ______
2. Choose the correct one: 片付ける(そばから / やいなや)散らかる — for a repeated complaint.
3. Translate into Japanese: "I forget as soon as I hear it." → ______
4. What's the nuance difference between 〜そばから and 〜が早いか? → ______
5. Fill in: 覚える___忘れるので、単語帳が手放せない。
6. Correct or wrong: そばから can be used for one-off happy news. → ______

### Answer key

1. 聞くそばから
2. そばから
3. 聞くそばから忘れる。
4. 〜そばから has a negative / annoyed nuance and is often repeated (wasted effort); 〜が早いか is neutral and one-off.
5. 覚えるそばから
6. Wrong — 〜そばから is for events that undo the result of X (negative / wasted-effort nuance), not for one-off happy news.

## Tips / key patterns

- Always dictionary form + そばから; don't use the ます or て form.
- Y usually undoes the result of X: forgetting, getting messy, running out, breaking.
- Often paired with 〜てしまう, which strengthens the annoyed nuance.
- In exam questions, the distractor keywords are the negative nuance and repetition.

## Summary

- Form: V-dictionary + そばから.
- Meaning: "as soon as X, Y right away" — Y usually undoes X.
- Negative / wasted-effort nuance, often repeated; good for complaints.
- Different from 〜やいなや / 〜が早いか (N3), which are neutral and one-off.
- Kanji: 奸 (cunning), 佞 (flatterer), 諂 (to flatter), 諛 (flattery), 媚 (to fawn), 傲 (arrogant), 慢 (haughty), 倨 (haughty), 驕 (arrogant; to treat), 奢 (to treat), 僭 (presumptuous).
