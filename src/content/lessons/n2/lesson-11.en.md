## Lesson goals

After this lesson, you can express firm concession in written language: "even if X / no matter what X is, the result stays the same". You can also distinguish the formality levels of all three forms and use set expressions like いずれにせよ and 理由はどうであれ.

## Explanation

**1. Forms.** This pattern attaches to three word types:

- noun + にしろ / にせよ / であれ (雨にしろ, 雨にせよ, 雨であれ)
- na-adjective without な + にしろ / にせよ / であれ (簡単(かんたん)にしろ, 簡単にせよ, 簡単であれ)
- verb in dictionary form + にしろ / にせよ (行くにしろ, 行くにせよ)

であれ comes from である, so it is **only** for nouns and na-adjectives — don't attach it after a verb. Formality order: にしろ < にせよ < であれ. であれ is the stiffest and most written.

**2. Meaning.** It means "even if / no matter how ...". This is a concession pattern: two contrasting situations are presented, then it is asserted that the result is the same.

- 雨にしろ晴れにしろ、試合は行われる (rain or shine, the match will still be held)
- 理由はどうであれ、約束は守るべきである (whatever the reason, a promise must be kept)

**3. Set expressions.** Memorize these three expressions:

- いずれにしろ / いずれにせよ = in any case, anyway
- 〜はどうであれ = no matter what 〜 is (理由はどうであれ, 結果はどうであれ)
- 誰にしろ / 何にしろ = whoever / whatever

This lesson's four kanji: 須 (す = obligation, e.g. 必須), 打 (だ = to strike/to open, e.g. 打開), 登 (とう = to appear/to rise, e.g. 登場), 線 (せん = line, e.g. 境界線).

## Example sentences

1. 〔文語・である体〕 理由はどうであれ、約束は守るべきである。(Whatever the reason, a promise must be kept.)
2. 〔文語・である体〕 雨にしろ晴れにしろ、試合は予定どおり行われる。(Rain or shine, the match will still be held as scheduled.)
3. 〔話し言葉〕 誰にしろ、この仕事は一人では無理だよ。(Whoever it is, this job can't be done alone.)
4. 〔ビジネス〕 いずれにせよ、来週までに結論を出す必要がある。(In any case, a conclusion must be reached by next week.)
5. 〔文語・である体〕 結果がどうであれ、努力した事実は消えない。(Whatever the result, the fact that he tried will not disappear.)
6. 〔話し言葉〕 行くにしろ行かないにしろ、連絡はすること。(Whether you go or not, you must get in touch.)
7. 〔文語・である体〕 原因はどうであれ、再発を防がなければならない。(Whatever the cause, recurrence must be prevented.)

## Tips / key patterns

- であれ comes from である. That's why it never follows a verb — for verbs there are only にしろ and にせよ.
- Different from 〜にしても (N3, casual/spoken): 〜にしろ・〜にせよ・〜であれ are firm and written in tone, suited to essays and speeches.
- The pattern 〜はどうであれ always uses であれ, not にしろ. This is a set expression.
- For na-adjectives, drop な first: 簡単にしろ (not 簡単なにしろ).

## Summary

- 〜にしろ・〜にせよ・〜であれ = "even if / no matter what ... is", a firm concession pattern.
- Forms: nouns / na-adjectives (without な) + all three; dictionary-form verbs + にしろ/にせよ only.
- Formality: にしろ < にせよ < であれ.
- Set expressions: いずれにせよ, 〜はどうであれ, 誰にしろ.
- Kanji: 須 (obligation), 打 (breakthrough), 登 (appearance), 線 (line).
