## Lesson goals

After this lesson, you will be able to run a half-mock — a timed simulation of the N2 first block (105 minutes) with time discipline: allocation per section, when to skip questions, optimal text order, and how to review per strand.

## Explanation

**Format.** N2 session 1 = 言語知識 + 読解 = 105 minutes (session 2 = Listening 50 minutes, drilled in L44). Half-mock = full timed simulation of session 1, no pauses and no notes.

**Time allocation:**

| Block | Content | Time |
|---|---|---|
| A | Vocabulary (文字・語彙) | 20 minutes |
| B | Grammar (文法) | 25 minutes |
| C | Reading (読解) | 50 minutes |
| D | Flagged questions + recheck | 10 minutes |
| Total | | 105 minutes |

Timer PER BLOCK, not per question: block over → move on.

**Skipping rule.** Blocks A/B: stuck >90 seconds → flag, move on. Block C: text exceeds its limit (short 5', long 10') → flag, move on. Block D: do the flagged ones; fill the rest with your best guess — a blank question = definitely wrong.

**Reading order:** short → medium → long LAST. Every question is worth the same points; don't let one text eat up 20 minutes.

**Review per strand.** Count the % correct per strand; below 60% becomes next week's priority. Note the PATTERN, not just numbers: "4 wrong in 〜ざるを得ない-type" is more useful than "grammar 60%".

## Example sentences

**Example schedule:** 00:00–00:20 Block A (vocab, ≤60 sec/question) → 00:20–00:45 Block B (grammar) → 00:45–01:35 Block C (reading, short texts first) → 01:35–01:45 Block D (flagged questions).

**Filled review table example:**

| Strand | Correct/Questions | Percent | Next week's action |
|---|---|---|---|
| Vocabulary | 18/25 | 72% | continue SRS as usual |
| Grammar | 12/20 | 60% | drill 〜ざるを得ない-type patterns |
| Reading | 10/16 | 63% | redo L42 technique (90-second scan) |

## Practice

1. What is the time allocation per half-mock N2 block (A–D)?
2. When are questions skipped? What goes in block D?
3. What is the recommended order for working through reading texts? Why?
4. How do you review results per strand?
5. Write your first half-mock schedule (date, time, place).

### Answer key

1. A vocab 20', B grammar 25', C reading 50', D flagged questions + recheck 10' (total 105').
2. Stuck >90 seconds (A/B) or past the text limit (C) → flag, move on; block D is for flagged ones + filling in everything left blank.
3. Short texts → medium → long last; each question is worth the same points, so secure the quick ones first.
4. Count % per strand; <60% = priority; note the PATTERN, not just numbers.
5. Correct example: "Saturday June 14, 09.00–10.45, bedroom (phone in airplane mode), per-block timer ready."

## Tips / key patterns

- The biggest enemy of the first half-mock is perfectionism: 5 minutes on one vocab question = stealing time from two reading questions.
- Don't "borrow" time between blocks.
- Do it at your actual exam hour so your body rhythm gets used to it.
- Keep the review table for diagnosis in L47.

## Summary

- Half-mock = N2 session 1 simulation: 105 minutes, no pauses, no notes.
- Allocation: vocab 20' + grammar 25' + reading 50' + flagged questions 10'.
- Skip: >90 seconds stuck → flag, move on; short texts → long.
- Review per strand: % + error patterns → next week's priority.
