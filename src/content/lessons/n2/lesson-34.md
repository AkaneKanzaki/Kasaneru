## Tujuan pelajaran

Setelah pelajaran ini, kamu bisa menulis atribusi sumber ala koran: menyebut "pihak" dengan 〜方 dan mengutip sumber dengan 〜によると/〜によれば. Kamu bisa mengombinasikannya dengan pola kabar L32–L33 dan menguasai 3 kanji baru.

## Penjelasan

**1. 〜方 — "pihak".** Pola: N + の + 方. Dipakai untuk menyebut lembaga atau orang secara formal dan menjaga jarak: 当局の方 (pihak berwenang), 関係者の方 (pihak terkait). Selalu pakai の — tidak pernah langsung menempel.

**2. 〜によると / 〜によれば — "menurut".** Pola: N + によると / によれば. Inilah cara wajib mengatribusikan sumber di berita: 記者によると, 気象庁によれば. Bentuk によれば sedikit lebih formal dan tertulis.

**3. Kombinasi lengkap.** Rumus berita sempurna: SUMBER + によると + ISI + penutup kabar. Contoh: 当局の方に よると、被害は 拡大しているとのことだ. Kamu boleh menutup dengan とのことだ (L32) atau ものとみられる (L33).

Tiga kanji pelajaran ini: 渚 (なぎさ = pantai), 啼 (な = berkicau atau menangis, mis. 啼く), 嗤 (し = seringai dingin, mis. 嗤笑 — review L33).

## Contoh kalimat

1. 〔新聞〕 当局の方に よると、被害は 拡大している模様だ。(Menurut pihak berwenang, kerusakan tampaknya meluas.)
2. 〔新聞〕 気象庁に よれば、あすは 霖雨とのことだ。(Menurut badan meteorologi, besok hujan berkepanjangan menurut kabar.)
3. 〔新聞〕 関係者の方に よると、会議は 延期されるとのことだ。(Menurut pihak terkait, pertemuan akan ditunda menurut kabar.)
4. 〔新聞〕 目撃者に よれば、事故は 夕方に 起きたとのことだ。(Menurut saksi mata, kecelakaan terjadi pada sore hari menurut kabar.)
5. 〔新聞〕 専門家に よると、この 島の 渚が 美しいとのことだ。(Menurut ahli, pantai pulau ini indah menurut kabar.)
6. 〔文語・である体〕 渚で 啼く 鳥の 声を 聞きながら、彼は 嗤笑を 浮かべた。(Sambil mendengar kicau burung di pantai, ia menyunggingkan seringai mengejek.)
7. 〔話し言葉〕 先輩に よると、あの 教授は テストが 厳しいとのことだ。(Menurut senior, dosen itu katanya ujiannya sulit.)

## Latihan

1. Isi partikel: 当局__方に よると (の / が)
2. Pilih yang lebih formal-tulis: 気象庁 (によると / によれば)
3. Ubah menjadi kalimat berita: 記者が 言った "会議は 延期される" → ______
4. Terjemahkan: "Menurut badan meteorologi, besok hujan berkepanjangan." → ______
5. Jelaskan bedanya: 〜によると vs 〜によれば.
6. Betulkan: 記者の によると、祭りは 延期だ → ______

### Kunci jawaban

1. の
2. によれば
3. 関係者の方に よると、会議は 延期されるとのことだ。
4. 気象庁に よれば、あすは 霖雨とのことだ。
5. Artinya sama ("menurut"); によれば lebih formal dan tertulis, によると netral lisan-tulis
6. 記者に よると、祭りは 延期だ

## Tips / pola penting

- 〜方 selalu didahului の: 当局の方 (benar), 当局方 (salah).
- Urutan baku: SUMBER + によると + ISI + penutup (とのことだ / 模様だ / ものとみられる).
- Jangan memakai 方 untuk diri sendiri atau teman akrab — kesannya terlalu menjaga jarak.
- Di headline, sumber sering dipadatkan: 気象庁、霖雨の 見通し.

## Ringkasan

- 〜方 (N + の + 方): menyebut "pihak" secara formal dan berjarak.
- 〜によると / 〜によれば: "menurut" — atribusi sumber wajib di berita.
- Rumus: SUMBER + によると + ISI + penutup kabar.
- Kanji: 渚 (pantai), 啼 (berkicau), 嗤 (seringai).

## Tugas & catatan SRS

Tugas: tulis 3 kalimat berita tentang kampusmu memakai rumus SUMBER + によると + ISI + penutup (variasikan penutupnya: とのことだ, 模様だ, ものとみられる). Masukkan ke deck SRS: 方, 当局, 関係者, によると, によれば, 気象庁, 目撃者, 渚, 啼く, 嗤笑.
