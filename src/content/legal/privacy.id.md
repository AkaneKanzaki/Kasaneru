# Kebijakan Privasi — Kasaneru

Terakhir diperbarui: 12 Oktober 2026.

Kasaneru adalah aplikasi belajar bahasa Jepang yang offline-first dan
open-source. Kebijakan ini menjelaskan bagaimana informasi ditangani
saat Anda menggunakan aplikasi.

## Versi singkat

**Kami tidak mengumpulkan, mengirim, menjual, atau membagikan data pribadi
apa pun.** Semua yang Anda lakukan di Kasaneru tetap di perangkat Anda.

## Data yang TIDAK kami kumpulkan

- Tidak perlu akun. Kami tidak meminta atau mengumpulkan nama, alamat email,
  atau data kontak apa pun.
- Tidak ada analitik, pengenal iklan, laporan crash, atau teknologi
  pelacakan dalam bentuk apa pun.
- Tidak ada cookie.

## Data yang tersimpan di perangkat Anda

Agar berfungsi, Kasaneru menyimpan hal berikut **hanya di perangkat Anda**
(di penyimpanan lokal aplikasi):

- Progres belajar: pelajaran yang selesai, latihan kana, review flashcard,
  riwayat ujian, XP, dan streak.
- Profil: bahasa, tema, nama tampilan, dan target level.

Data ini tidak pernah keluar dari perangkat Anda kecuali **Anda sendiri**
memilih mengekspor file backup (Profil → Export backup). File backup
tersimpan/terkirim ke mana pun yang Anda tentukan — kami tidak pernah
menerima salinannya.

## Hak Anda

Karena data Anda tetap bersama Anda, Anda selalu memegang kendali:

- **Akses dan portabilitas:** lihat progres langsung di aplikasi, atau
  ekspor kapan saja via Profil → Export backup.
- **Penghapusan:** Profil → Hapus semua data akan menghapus permanen
  seluruh data lokal di perangkat.

Kontrol ini tersedia untuk semua pengguna, sejalan dengan hak subjek data
di bawah GDPR Uni Eropa, CCPA/CPRA California, LGPD Brasil, dan
UU Pelindungan Data Pribadi Indonesia (UU No. 27 Tahun 2022).

## Anak-anak

Kasaneru tidak mengumpulkan data pribadi dari siapa pun, termasuk
anak di bawah 13 tahun. Aplikasi ini adalah alat edukasi untuk umum.
